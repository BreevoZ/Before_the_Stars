# Before the Stars

![Before the Stars 封面：深绿山峦、淡金色月亮、星点与横向战场地面](assets/cover.png)

一款受《Age of War》启发的网页策略游戏。现已支持 **原始 → 中世纪 → 文艺复兴 → 现代 → 未来** 五个时代，每个时代有三种兵、三种炮塔、专属大招和基地外观。另有金币、经验、双方独立进化、训练队列、电脑对手及炮位扩容。

时代路线和兵器题材参考原版；文艺复兴的全军治疗也参考了原版机制，数值与战斗节奏为本项目重新设计。资料：[原版玩法与时代](https://flashgaming.fandom.com/wiki/Age_of_War)、[现代时代](https://aowg.fandom.com/wiki/Modern_Age)、[未来时代](https://aowg.fandom.com/wiki/Future_Age)。本版每时代保持三种兵，未加入原版未来时代的第四种超级士兵。

## 运行

原生 JavaScript、Canvas 2D 和 CSS，无需安装依赖或构建。在项目目录启动静态服务器：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

浏览器打开 <http://127.0.0.1:8000>。项目使用 ES modules，需要通过 HTTP 访问。

## 操作与胜负

- 左侧青色为我方，右侧橙色为电脑。摧毁敌方基地获胜，我方基地被摧毁则失败，同一模拟帧双方基地同时被摧毁为平局。对局可以在任何时代结束。
- 点击三张兵种卡片或按 `1` / `2` / `3` 加入训练队列；`空格` 训练第一种前排兵。
- 击杀及己方士兵阵亡都会积累经验，达到下一时代门槛后点击进化或按 `E`；上方五段进度显示我方当前时代，双方时代以基地旁的罗马数字显示，悬停可查看时代名称与经验。
- 选中空炮位后点击炮塔卡片建造；`T` 在选中位置建造第一种炮塔。「+」购买空炮位；选中已有炮塔可拆除并返还原价一半。
- 点击大招或按 `Q`：攻击大招进入瞄准，再点击战场释放，也可用左右方向键、`Enter` 释放、`Esc` 取消。**复苏之光直接施放，无需选点。**
- 点击回转箭头或结算后的「再战一局」，重置双方时代、经验、基地、金币、队列、兵力、炮塔、扩容、大招及计时。切到其他标签页暂停。
- 兵种卡仅展示实际模型、价格与快捷键，名称在悬停时显示；队列显示训练进度，大招显示冷却。悬停查看详细属性与专属机制。点击「兵种图鉴」可查看五个时代全部兵种，并切换行进、攻击、待机和阵营。
- 点击右上角「？」或按 `?` 打开指挥手册，查看当前时代的三种兵、三种炮塔、技能和规则，手机也可查看。手册打开时暂停战斗和游戏快捷键，关闭按钮或 `Esc` 恢复。
- 支持手机触摸，训练与基地支援面板位于战场下方。

## 昼夜背景

战场从黎明开始，每 **120 秒对局时间**循环一次白昼、黄昏、夜晚与黎明。太阳和月亮沿天空移动，星光随夜色渐显，每颗星以约 **2.4–5 秒**的不同节奏明暗闪烁，亮星带有短暂微光；山峦与地面同步变色。暂停、打开手册或对局结束时昼夜停止，重开后回到黎明；开启系统「减少动态效果」时背景保持静态。循环时长可在 `src/render.js` 的 `DAY_NIGHT_CYCLE_SECONDS` 调整。

`assets/` 是本地素材目录，已加入 `.gitignore`，不会随普通 Git 提交上传；游戏背景由 Canvas 绘制，无需该目录的图片。

## 五个时代与独立进化

| 时代 | 进化所需累计经验 | 基地生命上限 | 每秒金币 | 基地外观 | 兵种 |
| --- | ---: | ---: | ---: | --- | --- |
| I · 原始时代 | 0 | 600 | 7 | 低矮石堡 | 棍棒人、弹弓手、恐龙骑兵 |
| II · 中世纪 | 160 | 900 | 10 | 城垛与旗帜城堡 | 盾剑士、长弓手、重甲骑士 |
| III · 文艺复兴时代 | 480 | 1500 | 16 | 砖石棱堡与拱门 | 决斗士、火枪手、野战炮组 |
| IV · 现代时代 | 1100 | 2400 | 24 | 雷达混凝土碉堡 | 刺刀突击兵、自动步枪兵、主战坦克 |
| V · 未来时代 | 2200 | 3800 | 36 | 发光能源要塞 | 光刃战士、等离子射手、悬浮战争机器 |

- 双方分别从 0 经验开始。击杀方获得该兵种 100% 的经验和击杀金币；阵亡方获得该兵种 **75% 的经验（向下取整）**，不获得金币。炮塔及大招击杀也计入，多个攻击同时击杀只结算一次。例如棍棒人阵亡，击杀方得到 20 经验和 10 金币，阵亡方得到 15 经验。双方遵守相同规则，因此不出兵不能阻止电脑积累经验。等待、训练、取消订单、拆塔、治疗和攻击基地不增加经验。
- 进化不花金币、不扣累计经验，每次升一个时代。玩家手动进化，电脑达到自己的门槛后独立进化；只有该方的基地、收入和可购兵种／炮塔发生变化。
- 进化保留已受伤害，当前生命增加新旧生命上限的差额。例如 `220 / 600` 变为 `520 / 900`。未来时代达到上限，不再进化。
- 招募和炮塔卡片随时代切换；旧兵保留原属性，已付款订单保留兵种、进度、原价和顺序，旧炮塔及扩容保留。不能再购买低于当前时代的兵或塔。
- 飞行中的弹药、已释放的大招及剩余冷却不会被进化重置。文艺复兴治疗在进化后继续生效至原定结束时间。任何新大招都必须等待现有冷却结束。

士兵自动前进，优先攻击射程内敌军，然后攻击基地。近战与重装单位在前排排队，远程射手使用后排，前排兵可越过己方射手。五个时代的部队可以共存。恐龙、骑兵、炮组与载具按实际体型预留队列及出生间距，停止移动后脚步和车轮随之停止。

护甲减少每次物理命中的伤害，最低 1 点。决斗士忽略 3 点护甲，等离子射手忽略 8 点；火枪手与光刃战士完全无视护甲。盾剑士对单体弹药在扣除护甲后再减伤 30%，完全穿甲弹除外；不减免爆炸或近战伤害。子弹、炮弹和能量弹都有飞行时间，单体弹药不会在目标死亡后转移伤害。野战炮组、坦克、悬浮战争机器分别有 **55 / 70 / 90** 的爆炸半径，范围内不伤友军，原目标死亡后仍会在最后追踪点爆炸。它们对基地的攻城射程分别为 **360 / 420 / 500**，能够在同代炮塔的射程外轰击基地；对士兵仍使用表中的较短射程，近处有敌军时优先攻击敌军。需要派部队拦截，或用攻击大招处理攻城单位。它们不会通过爆炸对基地重复结算。

### 造型与专属动作

部队与山峦、基地共用低饱和的绿灰、石色与土金色，以无外描边的平面色块和少量明暗分面表现材质。缩小头部、简化五官与装饰，保留头盔、武器、披挂和载具轮廓作为时代识别；步伐起伏、枪口火光与能量尾焰保持克制。

| 时代 | 视觉识别 | 专属动作与用途 |
| --- | --- | --- |
| 原始 | 兽皮棍棒人、Y 形弹弓、带骑手的长尾恐龙 | 挥棍、拉弓叉发石弹、恐龙四足行进与咬击；咬击额外伤害一名邻近敌兵，副目标承受 45% 基础伤害 |
| 中世纪 | 锁甲与鸢盾、兜帽长弓、披挂战马与骑枪 | 盾牌格挡、拉弓放箭、骑马挺枪；骑士连续前进 80 距离后首击增加 32 伤害，攻击后消耗，堵塞停步会清空蓄积 |
| 文艺复兴 | 羽帽与细剑、长身火枪、铜炮与木轮炮组 | 弓步刺剑、火枪后坐与烟雾、车轮随行程转动、炮管后坐 |
| 现代 | 钢盔与刺刀、带弹匣步枪、履带坦克 | 刺刀前刺、站定蹲姿三连点射、履带滚动与主炮后坐；连射目标死亡或离开射程即取消余下发射 |
| 未来 | 全封闭面罩、分段能量装甲、双管悬浮重炮 | 光刃拖影、能量武器蓄光、悬浮起伏与推进尾焰 |

所有造型通过 Canvas 绘制，招募缩略图与战场使用相同模型；阵营通过披挂、饰条和能量颜色区分。`units.html` 是可独立打开的动态图鉴。原作的洞穴人、弹弓手、恐龙骑兵、骑马骑士和未来悬浮单位作为题材参考，数值与新增特性属于本版设计。参考：[原作介绍](https://www.maxgames.com/play/age-of-war.html)、[兵种资料](https://flashgaming.fandom.com/wiki/Age_of_War)、[恐龙与悬浮战车](https://www.crazygames.com/game/age-of-war)。

## 金币与训练

- 初始双方各 180 金币，被动收入按各自时代结算，击杀另有奖励。进化不会赠送一次性金币。
- 购买立即扣费，按先后顺序逐个训练。队列最多 5 位，正在训练也占一位。
- 双方兵力上限各 16，场上部队和训练队列共同占用。
- 点击订单可取消，包括正在训练的订单，全额退还原始费用，其余订单保持顺序。
- 出口被同排友军堵住时，完成训练的士兵保留在队首，等出口腾空后出现。

## 电脑对手

电脑使用相同的时代收入、击杀与阵亡经验、击杀金币、经验门槛、单位属性、购买价格、训练时间和炮位规则，不免费出兵，也不因玩家进化获得经验。

开局 2.4 秒后，每隔 1.8 秒评估，经验达标则进化。敌基地旁的剑／火炮图标表示当前战术，悬停可查看名称：

- **混合推进**：使用当前时代的兵种维持前排、补充射手并积攒重型单位费用，旧兵也纳入阵容判断。基地受到威胁时优先恢复防守；面对远距攻城单位，会出兵拦截，不会继续购买打不到目标的炮塔。
- **重装攻城**：看到玩家有炮塔、场上不超过两名士兵，且自家基地附近没有敌军时，攒足一整波费用再训练。重型单位先出场，随后远程支援，第三位交替为前排兵或射手；文艺复兴起，面对两座以上炮塔改为两名攻城单位加一名射手。波次仍逐个训练、受兵力上限限制，按正常价格付费；资金不足就等待，基地受威胁则切回混合推进。
- **基地防御**：18 秒后，基地受损或附近敌军较多时购买当前时代炮塔。密集敌军优先范围塔，装甲目标优先穿甲塔，其余选最快射速。炮位已满且能负担扩容、新塔和一名前排兵时会扩容。

电脑不读取玩家的金币或待训练订单来选择战术，没有大招。纯造塔可以争取发展时间，但持续防守会让电脑从阵亡中积累经验，并逐步派出远程攻城单位。
