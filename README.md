# Before the Stars

一款受《Age of War》启发的极简网页策略游戏。从原始时代推进到未来时代，训练部队、部署炮塔，摧毁敌方基地。

原生 JavaScript、Canvas 2D 与 CSS，游戏无需安装依赖或构建。场景、部队、炮塔与图标均由代码绘制。开发用无头模拟与纯逻辑测试使用 Node 24+，也没有第三方依赖。

## 本地运行

在项目目录启动静态服务器：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8000>。项目使用 ES modules，需要通过 HTTP 访问。

- 默认增量模式：`/`（原入口 `/?mode=incremental` 仍可使用）
- 经典模式：`/?mode=classic`，入口在战场底部
- 快速调试：`/?mode=debug`，入口在战场底部，使用独立存档
- 兵种图鉴：`/units.html`
- 炮塔图鉴：`/turrets.html`
- 动画工坊：`/animations.html`（无需开局）
- 浏览器测试：`/tests/`

### 在线手机测试

试玩地址：[Before the Stars](https://breevoz.github.io/Before_the_Stars/) · [快速调试](https://breevoz.github.io/Before_the_Stars/?mode=debug)。

GitHub Pages 从 `main` 分支的根目录发布，`.nojekyll` 保证原生静态文件直接提供；不需要安装依赖或编译。向 `main` 推送更新后自动发布，可在仓库 Actions 中查看部署结果。`assets/`、本地托管配置和环境文件均被 Git 忽略，不会上传。

如需迁移其他静态托管，可运行 `python3 scripts/prepare-site.py`，仅将 Git 已跟踪的网页、`src/` 和浏览器测试复制到忽略的 `dist/`。本地开发仍直接从项目根目录启动。

手机打开站点首页即可试玩，`/?mode=debug` 可快速测试进化和重建，底部保留经典模式与图鉴入口。建议分别检查竖屏与横屏的招募、炮位选择、大招瞄准、暂停、存档及结算对话框。手机与电脑的存档独立；需要迁移时通过「存档」导出／导入。

### Node 测试与无头模拟

安装 Node 24 或更高版本后，在项目根目录直接运行，无需 `npm install`：

```bash
npm test
npm run sim
mkdir -p sim/results
npm run sim:batch -- --out sim/results/scan.csv
```

- `npm test`：Node 内置测试器运行共享的战斗、文明、自动化、存档、动画运动学用例，以及模拟器／CSV／命令行测试；失败时退出码为 1。
- `npm run sim`：读取 [sim/example.json](sim/example.json)，输出一次完整文明模拟的 JSON。指定自己的配置：`node sim/run.js path/to/run.json`。
- `npm run sim:batch`：读取 [sim/grid.example.json](sim/grid.example.json)，扫描生产等级 × 挑战等级 × 编队比例的 18 种组合。指定网格：`node sim/batch.js path/to/grid.json --out sim/results/scan.csv`。
- 不传 `--out` 时 CSV 写到标准输出，进度写到标准错误；可用 `node sim/batch.js > sim/results/scan.csv` 重定向。`sim/results/` 已忽略，不上传批量结果。
- 浏览器回归仍在 `/tests/`，运行同一批纯逻辑用例及 Canvas、UI、键盘、响应式和刷新恢复测试。Node 不模拟 DOM，也不代替视觉验证。

模块入口是 [sim/simulate.js](sim/simulate.js) 的 `simulateRun({ talents, challengeLevel, automation, maxSeconds })`，同步返回：

| 字段 | 含义 |
| --- | --- |
| `outcome` | `won` 通关、`lost` 战败、`draw` 平局、`timeout` 超时未完成 |
| `duration` | 本轮所有冲突的总模拟秒数，不是电脑执行耗时 |
| `battles` | 每场的 `number`、`duration`、`outcome`、敌方起始／结束时代和玩家结束时代；包含超时的未结束战斗 |
| `peakGold` | 我方金币余额峰值，包含起始资源与转场退款，按每帧及转场后采样 |
| `totalExperience` | 我方本轮累计获得的击杀与阵亡经验，包含战争档案增益 |
| `legacy` | 本轮终局实际结算所得；普通胜利、战败、平局和超时不发奖 |

`talents` 使用 [src/talents.js](src/talents.js) 中的节点 ID → 等级，包含 `production` 和 `warfare`；省略的节点为 0。这是一套用于数值实验的已购天赋配置，不扣浏览器存档中的遗产。节点等级和前置必须有效，`challengeLevel > 0` 需要 `challenge` 天赋。难度范围 0–10。

`automation` 接受游戏现有设置，例如 `enabled`、`target`、`mode`、`weights`、`evolve`、`defense`、`elite`；省略项沿用游戏默认值，**默认关闭**，功能必须已由天赋解锁。`unlocked` 从根节点推导，不能手填。调用 `simulateRun()` 不传配置，表示新文明无人操作，通常会战败；可从示例配置开始调整。

模拟固定使用游戏的 1/60 秒步长，复用真实 AI、付费招募、自动购买和文明结算。普通胜利自动继续同一文明，未来敌军基地被摧毁后结束。不自动重建，不额外施放技能或代替未解锁的自动进化；因此结果衡量配置的无人值守表现，不代表手动操作的胜率。默认时限为整轮 1800 模拟秒，可设 `maxSeconds`，最大 86400 秒，向下对齐完整帧。相同代码版本和配置会得到相同结果，随机 runId 不参与战斗或统计。

批量配置由 `base`（共用配置）和 `grid`（参数路径 → 候选值数组）组成，取笛卡尔积。例如 `"challengeLevel": [0, 1, 2]`、`"talents.production": [1, 3, 5]`、`"automation.weights": [[2, 2, 1], [1, 1, 3]]`。每个组合先校验，缺前置或非法设置会报出行号，不静默修正；单批最多 10000 组。CSV 包含扫描参数、胜负、总时长、逐场时长、金币峰值、经验、遗产及完整配置 JSON，便于筛选与复现。所有组合验证和运行成功后才写入 `--out` 文件；该文件存在时会替换它。

## 玩法

默认入口为**增量模式**。经典模式保留在战场底部的小字入口中，保留经典战斗规则，不读取或应用永久增益。两种模式复用同一战斗模拟、部队、炮塔、图鉴和渲染；默认 `createGame()` 仍保持经典战斗规则。

左侧绿灰色为我方，右侧土橙色为电脑。部队自动前进、攻击射程内的敌军，再攻击基地。摧毁敌方基地获胜；同一模拟帧双方基地同时被摧毁为平局。

| 操作 | 方法 |
| --- | --- |
| 训练部队 | 点击部队卡，或按 `1` / `2` / `3`；未来时代另有 `4` 超级士兵 |
| 暂停／继续 | `空格` 或顶部暂停按钮；瞄准时空格也只暂停，长按不反复切换 |
| 取消训练 | 点击队列中的订单，退还原价 |
| 时代进化 | 经验达标后点击上箭头，或按 `E` |
| 建造炮塔 | 先选空炮位，再点炮塔卡；`T` 建造第一种炮塔 |
| 扩容／拆塔 | `+` 购买炮位；选中已有炮塔后点击拆除，返还原价一半 |
| 释放大招 | 点击大招或按 `Q`；攻击技能再点击战场选点，治疗直接施放 |
| 键盘瞄准 | 左右方向键移动落点，`Enter` 确认，`Esc` 取消 |
| 查看资料 | 悬停卡片，或打开 `?` 指挥手册、兵种／炮塔图鉴 |
| 重新开始 | 点击回转箭头或结算页的「再战一局」 |

主界面卡片只展示模型、价格与快捷键，名称和属性放在悬停提示中。手机可通过指挥手册和图鉴查看完整资料。图鉴支持动作、阵营和暂停控制。

### 经济与进化

- 双方起始 180 金币，原始时代每秒收入 7 金币；训练队列最多 5 位，每方兵力上限 16，包含训练中的订单。
- 击杀获得金币与完整经验；阵亡方获得该兵种 75% 的经验，向下取整。等待、建造、取消训练不会增加经验。
- 双方独立进化，玩家手动操作，电脑自动操作。进化不消耗金币和经验；基地增加生命上限与相同数额的当前生命，保留已受伤害。
- 旧兵、已付费订单、旧炮塔、飞行中的弹药和地面效果在进化后保留；购买列表切换到当前时代。
- 每方初始 1 个炮位，额外三个炮位分别需要 100、160、240 金币。

| 时代 | 累计经验门槛 | 基地生命上限 | 每秒收入 | 部队 |
| --- | ---: | ---: | ---: | --- |
| 原始 | 0 | 600 | 7 | 棍棒人、弹弓手、恐龙骑兵 |
| 中世纪 | 160 | 900 | 10 | 盾剑士、长弓手、重甲骑士 |
| 文艺复兴 | 480 | 1500 | 16 | 决斗士、火枪手、野战炮组 |
| 现代 | 1100 | 2400 | 24 | 匕首突击兵、自动步枪兵、主战坦克 |
| 未来 | 2200 | 3800 | 36 | 光刃战士、等离子射手、悬浮战争机器、超级士兵 |

### 部队与炮塔

部队通过装备轮廓和动作区分时代：兽皮、鸢盾、羽帽、钢盔、能量装甲依次演进。恐龙可咬击两个目标，骑士连续行进后获得冲锋伤害，盾剑士减免单体弹药，步枪兵三连点射；攻城单位可在较远距离轰击基地。

**超级士兵**参考原作的高价终局兵种定位，作为未来时代第四个手动招募选项（快捷键 `4`），经典、增量和调试模式均可使用。当前原型为 3000 金币、12 秒训练、6000 生命、32 护甲；远程每 0.55 秒发射 320 伤害的穿甲能量弹，目标进入 60 距离时改用 440 伤害的近身短打，攻城射程 540。外观参考原作未来射手一系的科幻步兵轮廓：普通步兵体型、深色紧身作战服、银灰贴身轻甲、分段护胫、半覆式头盔与细窄能量目镜，配紧凑能量短枪。以放松的待机姿态、短促点射和轻护手短打表现独行精锐的高爆发，维持低饱和、少量发光细节的极简风格。它仍占一名兵力并走普通训练／退款流程；为帮助玩家突破僵局，仅供玩家招募，电脑与基础自动招募仍使用原来的三个兵种；解锁「精锐征召」后可自动招募超级士兵。数值按本作经济重新设计，后续可继续试玩调整。

炮塔仅攻击射程内的敌方部队，每个炮位独立瞄准、装填和开火。三种同代炮塔各有用途：

| 时代 | 炮塔 | 机制与动作 |
| --- | --- | --- |
| 原始 | 弹石器、自动蛋塔、原始投石机 | 弹力抛石、快速抛蛋、巨石范围砸击；弦回弹、料斗振动与投掷臂回收 |
| 中世纪 | 重型投石机、火焰投石机、沸油锅 | 配重投石、持续燃烧、近城烫伤减速；火弹装填与油锅倾倒 |
| 文艺复兴 | 轻型加农炮、重型加农炮、爆破加农炮 | 快速直射、完全穿甲重弹、范围榴弹；炮管后坐与复位 |
| 现代 | 单管炮塔、双管炮塔、火箭发射塔 | 稳定点射、双管交替、火箭范围轰炸；跟踪瞄准、独立后坐与导轨装填 |
| 未来 | 钛金射击塔、激光炮塔、离子射线塔 | 动能贯穿、高频穿甲脉冲、充能射线；轨道放电与充能翼展开 |

特殊规则：

- **火焰与沸油**：落点留下持续 2.4 秒的敌方伤害区域。火焰每 0.4 秒造成 6 点伤害；沸油每 0.4 秒造成 5 点伤害，并将区域内敌人的移动速度降至 55%。持续伤害无视护甲，不伤友军和基地；离开油区即恢复移速。
- **双管交替**：每轮两发，各造成 62 点基础伤害，间隔 0.16 秒。目标死亡或离开射程时取消余下射击，不转移到新目标。
- **贯穿**：钛金弹额外命中原目标后方 90 距离内的一名敌人，伤害为 60%；离子射线充能 0.65 秒后，额外命中后方 130 距离内的两人，伤害为 65%。贯穿不能超出炮塔射程，离子充能在目标丢失时取消。
- **拆除与进化**：已发射弹药、已落地火焰与沸油继续生效；拆塔会取消尚未发射的连射和充能。进化保留旧炮塔的连射、充能与冷却。

完整价格、射程、伤害和冷却直接从配置生成到图鉴与悬停提示，避免文档与游戏数值重复维护。

### 大招与电脑对手

五个时代分别拥有陨星天降、箭雨齐射、复苏之光、轰炸空袭与轨道打击。大招冷却独立于进化；进化不能重置冷却，也不会取消已释放的大招。

电脑遵守相同的金币、训练和进化规则。通常混合推进；面对炮塔会积攒资金组织攻城波次，基地受威胁时优先防守。电脑没有大招。纯造塔可以争取时间，但不能阻止电脑通过阵亡经验进化。

## M1：地表文明的重建循环

直接打开首页即可进入，也兼容 `/?mode=incremental`。**首次击败未来时代敌方基地、完成有效循环后**，顶部才会显示 Legacy 余额和「天赋树」「自动购买」入口，之后重建与刷新均保留入口。普通战役胜利、仅进化至未来、战败和平局不会解锁。首次通关前战败可直接从原始时代重试。`空格`／顶部「暂停」停止战斗；打开天赋树、自动购买、存档或手册、隐藏页面同样暂停。

1. **普通战役胜利**：被击败的敌人尚未到未来时代时，点击「继续文明进程」。仍属同一文明，新敌人从刚被击败敌人的时代 +1 开始。我方金币、经验、时代、炮位和炮塔保留，基地按当前时代恢复满血，未完成订单按实际支付价格退款。场上部队、弹药、地面区域和技能效果清除；大招及炮塔冷却保留，未发出的连射和充能取消。进化可手动进行，也可解锁「技术托管」后自动进行。
2. **文明终局**：击败**未来时代敌方基地**后，战争获胜但文明毁灭。每轮有效完成仅计入 1 次循环，基础获得 1 点文明遗产，可由本轮生效的遗产天赋与挑战难度提高。仅自己进化到未来不算通关，普通胜利、战败、平局和主动重开均无遗产。
3. **回到文明星图**：终局结算后自动进入全屏文明界面。战场暗下，废墟上浮现天赋星图；奖励已一次性入账，演出可跳过，不参与奖励判定。底部始终可以直接重建，解锁挑战后也可进入更高难度。刷新结算存档直接恢复星图，不重复播放演出或发奖。
4. **重建文明**：清除本轮金币、经验、时代、军队、订单、炮位与炮塔，从原始时代开始；保留循环次数、遗产、永久升级和自动招募偏好。战败也可保留永久进度重试。主动放弃未完成文明须确认；重开不等于清空存档。

### 天赋树与自动购买

**首次有效通关后**，战场上方常驻显示 Legacy 余额，并提供独立的「天赋树」和「自动购买」入口。天赋界面是全屏的**文明星图**，只有一个底部根节点 **Autobuyer（1 Legacy）**，向外展开自动化、文明增益、遗产收益三条路线，所有节点位于同一张星图，没有分支分页。SVG 曲线连接真实购买前置，主干较粗，已解锁路径点亮；手机保留至少 56px 的节点尺寸，先定位到根节点，再纵向浏览。Autobuyer 的开关与设置保留在独立界面。已有生产、战争档案保留原价和等级，作为文明增益分支。所有天赋仅在毁灭或战败后、下一轮开始前用 Legacy 购买；新一轮保存等级快照，读档不会重复应用效果，结算后购买也不会追补本轮遗产。节点展示前置、当前与下一级效果、价格及锁定原因。文明增益仅作用于我方；经典模式不受天赋或挑战影响。

星图交互：

- 普通天赋为 58–64px 六边形，关键天赋为更大的圆形光晕节点，专精为菱形；图标用 SVG 绘制，废墟复用战场基地模型。
- 节点直接显示等级点（如 `●●○`）与下一级价格。前置满足且买得起时呼吸发光，未满足前置或遗产不足时压暗。
- 鼠标悬停或点击、键盘聚焦节点后出现详情浮层，显示**当前 → 下一级**对比。桌面贴近节点，手机为底部浮层；没有固定侧栏。
- `Tab`、方向键浏览节点，`Enter` 打开／购买；`Esc` 先关闭详情，再返回战场。自动购买和存档仍有独立入口。
- 购买成功时连线流光、节点弹动、Legacy 数字跳动，余额立即显示真实扣费结果。减少动态效果设置会关闭演出、呼吸、流光和弹动，保留静态状态与文字反馈。
- 打开星图暂停战斗与自动购买，隐藏的战场 Canvas 也停止逐帧重绘。关闭后恢复原先的暂停状态。

| 档案 | 每级效果 | 最高等级 | 逐级价格（文明遗产） |
| --- | --- | --- | --- |
| 生产档案 | 被动金币收入 × `1.5 ^ 等级` | 5 | 1、2、4、8、16 |
| 战争档案 | 玩家战斗经验 × `1.25 ^ 等级` | 5 | 1、2、4、8、16 |

生产档案不改变击杀金币。经验先计算经典基础奖励：击杀完整经验，阵亡为 `floor(基础经验 × 0.75)`；再对每笔玩家奖励计算 `floor(经典奖励 × 战争档案倍率)`。敌军、经典模式和图鉴基础属性不受影响。收入提示、进化提示和文明档案显示同一份本轮倍率。

首次有效循环只解锁天赋树，**必须先花 1 Legacy 购买 Autobuyer 根节点**，才能使用基础自动招募并购买三条路线的天赋，解锁后默认关闭。基础界面仅提供开关与目标；预算、编队、进化、防御和精锐设置在购买对应天赋后才出现。玩家选择「前排 / 远程 / 重型」位置，每 0.25 秒模拟时间尝试正常付费招募一次；进化后自动解析新时代理应对应的兵种。仍遵守金币、训练队列及兵力上限。暂停、页面隐藏、胜利或文明结算时停止，不积累离线尝试。

| 分支 / 天赋 | 前置 | 逐级价格 | 效果 |

终局遗产统一计算为 `floor((1 + 遗产保存等级) × (1 + 0.5 × 文明传承等级) × (挑战等级 + 1))`，所有倍率相乘后仅向下取整一次。常规文明（挑战 0）最高每轮 8 点，挑战 10 最高每轮 88 点。使用本轮快照，且同一文明只结算一次；例如保存 2 级、传承 1 级得到 `floor(3 × 1.5) = 4`。天赋价格、效果与前置集中在 `src/talents.js`，属于待试玩调整的原型数值。重建储备只在开始新文明时发放，继续同轮冲突与刷新不再发放；生产档案仍只影响被动收入，击杀金币由战利品回收单独控制。

战场上方独立的「自动购买」窗口按已购天赋逐步提供以下功能，打开时暂停战斗：

- 基础开关和单一招募目标。后勤调度解锁预留金币、1–5 个队列上限、独立招募开关与购买优先级；其他高级功能随对应天赋解锁，默认关闭。基础默认预留 0 金币、正常 5 位队列；不开启高级功能时仅招募指定位置的部队。
- 编队比例每项 0–10，不能全为 0；0 表示不再购买该类。统计现有部队、旧时代部队与已付费订单，优先补充缺少的类型，不取消已有订单。精锐另设数量目标，优先储蓄补足。
- 显示当前待执行目标、预留外可用金币与等待原因。优先目标买不起时先存钱，不用便宜购买耗尽资金；队列或兵力已满时可处理防御。交替模式每次成功购买后让另一类先执行，调度顺序随存档保留。
- 炮塔按当前时代的第一／第二／第三种位置选择，可设 1–4 个目标炮位。扩容先存够炮位和炮塔全部费用；替换只针对旧时代炮塔，按原价一半返还，存够净支出与预留金额后才拆塔，不反复替换同代炮塔。
- 所有购买调用正常招募、建造、扩容和拆除流程，保留价格、队列、兵力及时代限制。预留金币与自动队列上限不限制手动操作。自动化不施放大招、不自动继续战役、不自动重建，也不产生离线收益。

原型假设集中在 `src/progression-config.js`：地表终点明确固定为 age 5；新敌人的初始金币按原始至未来为 180 / 300 / 480 / 720 / 1080，经验为对应时代门槛，基地满血、一个空炮位。升级与自动化数值均待试玩调整。M1 不包含 Bypasser、Orbital 文明层或第二层重置；原有未来时代「轨道打击」战斗技能保留。

### 可选文明挑战

在遗产收益分支购买 **文明挑战**（前置：遗产保存 1 级，花费 2 Legacy）后，终局会出现两个选择：

- **重建文明 / 结束挑战 · 常规重建**：从原始时代开始常规难度，保留永久进度。
- **挑战更强文明**：先查看下一轮敌军倍率和通关遗产，再开启高一级挑战。仍从原始时代开始，使用新 runId 和最新天赋快照；本轮金币、经验、军队与防御清空。

通关奖励已经入账，选择挑战不需要押上已有遗产；战败、平局或主动放弃无新奖励，也不扣旧奖励。战败可重试当前难度或返回常规文明，主动重开保持当前难度。只有击败未来时代敌方基地才可升一级；早期战役胜利继续同一文明，保留难度与资产。回到常规文明后，下一次挑战从 1 级重新攀升。原型上限为 **挑战 10**，通关后可常规重建。

倍率相对于常规文明计算，集中配置在 `src/progression-config.js` 的 `CHALLENGE`：

| 挑战等级 L | 倍率 |
| --- | --- |
| 敌军起始金币、被动收入 | `1.35 ^ L` |
| 敌军击杀与阵亡经验 | `1.2 ^ L` |
| 敌军部队生命、全部攻击伤害（含炮塔与地面效果） | `1.25 ^ L` |
| 敌军基地生命 | `1.2 ^ L` |
| 通关遗产 | `L + 1` |

起始金币向下取整，部队与基地生命四舍五入；经验沿用先算基础阵亡奖励、再乘倍率逐笔向下取整的规则。伤害在护甲与盾牌减伤前乘一次倍率，投射物读档不会二次加成。击杀金币、价格、兵力上限和训练时间不因挑战改变。图鉴继续展示基础属性。界面中的敌军倍率保留三位小数，模拟使用完整精度。

例如遗产保存 1 级、文明传承 0 级：常规通关 +2，挑战 1 通关 +4，挑战 2 通关 +6。保存 2 级、传承 1 级、挑战 2 的奖励为 `floor(3 × 1.5 × 3) = 13`。这些倍率、天赋价格和上限是待试玩调整的默认值；目前增加的是数值难度阶梯，敌军仍使用现有兵种与 AI。

### 存档与恢复

增量模式使用带版本号的浏览器本地存档（当前版本 **5**），同时保存永久数据、天赋与本轮等级快照、累计遗产收支、自动购买设置与调度顺序、本轮挑战难度、敌军倍率、本轮结算标记和完整战斗状态。刷新可恢复普通胜利或毁灭结算页，不重复退款、发奖或叠加倍率。版本 1、2、3、4 的有效存档自动迁移，保留现有进度、已购天赋、余额与自动购买偏好。版本 1、2 已开放的免费招募和预算功能会保留为「Autobuyer」「后勤调度」天赋。版本 3 玩家如果已经购买文明或遗产增益、尚未购买根节点，会免费补齐新增的根节点前置；尚无天赋的玩家仍需花 1 Legacy 正常解锁。兼容赠予单独记账，不扣余额、不虚增累计遗产，也不自动开启招募。迁移不重新结算、不补发金币，首次写入时将原有效记录保留为备份。版本 4 迁移后挑战难度为 0、新天赋未购买，不重新发奖或改变现有敌军。未知版本或损坏记录仍受保护。

- 每 10 秒模拟时间自动保存；结算、继续冲突、购买升级、设置自动招募、重建及隐藏／关闭页面时立即保存。关闭期间**没有离线收益，也不推进战斗**。
- 战场底部「存档」从开局即可使用；解锁档案后也可从其中进入。该入口提供手动保存、JSON 导出、文件／文字导入和恢复上一份有效备份。导入先校验版本、字段类型、数值范围与状态一致性，再确认替换。
- 损坏或未知版本的原存档会被保护，自动保存停止覆盖；可恢复备份、导入有效存档或确认清空。此时仍可试玩、导出当前内存进度。
- 存储被禁用或空间不足时显示提示，游戏继续运行；请导出保存。另一标签页写入存档后，旧页面也会停止覆盖并提示刷新。
- 「清空全部进度」须明确确认，会删除永久进度及本地备份。导出的文件不受影响。存档按浏览器和站点地址隔离，切换端口或浏览器需导出再导入。
- 浏览器崩溃或强制结束可能丢失最近一次自动保存之后的操作；关闭事件只是额外保存机会，不替代定期保存。

### 验证完整循环

正常试玩：进入增量模式 → 出兵、手动进化并获胜 → 若敌人尚未到未来则继续文明 → 摧毁未来敌方基地 → 自动进入文明星图 → 花 1 Legacy 解锁 Autobuyer 根节点 → 重建 → 从独立「自动购买」入口开启并选择目标。此时回到原始时代，Legacy 常驻显示 0；刷新后天赋与设置仍保留。第二次终局可以直接重建，也可进入天赋树，用新遗产解锁后勤调度／编队，或购买生产档案使下一轮收入变为 `+10.5/s`。

自动验证：启动静态服务器后打开 `/tests/`，等待页面顶部显示通过数量及 0 failed。除原有战斗、界面和动画回归，还覆盖天赋前置与等级上限、遗产收益快照、起始金币与击杀金币隔离、自动购买预算／编队／防御／精锐、v1/v2/v3/v4 存档迁移、唯一根节点对三条路线的购买限制、渐进功能解锁、真实前置连线、独立窗口暂停、后续终局直接重建、挑战难度与奖励阶梯、敌我隔离、投射物/炮塔/地面伤害、重复点击、战败重试和新存档校验。增量 UI 测试使用独立内存存储，通过真实伤害触发结算，实际操作继续、购买、配置、重建，再重新加载验证，并检查 320px 宽度布局。全屏星图测试还覆盖 SVG 前置曲线、节点尺寸与避让、等级点和价格、详情悬停／键盘／触摸、单次购买反馈、毁灭演出跳过／刷新恢复、减少动态效果和战斗暂停。

### 快速调试

打开 `/?mode=debug`，或点击战场底部「快速调试」。顶部会显示「调试 · 独立存档」工具栏。

- 默认 **10 倍模拟速度**，可选 1／5／10／20 倍。训练、行军、战斗、冷却和自动招募一起加速，仍使用固定步长；空格或按钮暂停、打开天赋树／自动购买／存档／手册、隐藏页面均停止推进。
- 每个新文明额外提供 **10000 金币**，经验补足到可手动进化至未来；仍需点击进化或按 `E`，不会自动进化。读档不重复补发资源。「补充资源」可再次添加测试金币并补足经验。
- 「战役胜利」摧毁当前敌方基地；「终局结算」将敌人推进至未来后摧毁基地；「战败」摧毁我方基地。三者都走现有流程状态机，方便快速检查继续冲突、遗产、升级与重建。
- 调试存档和备份与正式增量模式完全分开，导出文件带 `debug` 标识，正式模式拒绝导入调试存档；清空调试进度不会清空正式进度。速度设置会随调试存档保留。

测试超级士兵：在调试模式连续按四次 `E` 进化至未来，按 `4` 训练；空格暂停检查。动画工坊搜索「超级士兵」可分别预览行军、射击与近身短打。

最快验证：新调试存档点「终局结算」→ 自动进入文明星图 → 点根节点并购买 Autobuyer →「重建文明」→ 独立自动购买入口开启招募。再次「终局结算」后可在星图底部直接「重建文明」；也可查看天赋，逐轮解锁高级功能。已有调试存档保留原有解锁，不会重新演示新玩家限制。10 倍速度下每现实秒推进约 10 个模拟秒。

快速验证挑战：在调试模式逐轮点「终局结算」并重建，攒够遗产后依次购买 Autobuyer → 遗产保存 1 → 文明挑战（共 5 Legacy）。通关页点「挑战更强文明」→ 确认挑战 1 →「终局结算」，应获得 +4 Legacy，并可挑战 2（预览 +6）。刷新后奖励、难度与结算页保留；也可点「战败」验证原难度重试与返回常规文明。调试模式与正式存档隔离。

## 画面与动画

低饱和色块、无粗描边轮廓和少量明暗分面统一场景、部队与炮塔。战场、建造／招募卡和动态图鉴使用同一套模型。

恐龙采用双足承重，马采用四足错相步态。支撑脚按实际行进距离贴地，摆腿时抬脚。马的前腿分为肘、腕、球节与蹄，承重时较直、抬蹄时折收；后腿的膝关节向前、飞节向后，分别求解，避免反关节。攻击时恐龙探颈咬合、骑手同步送出石矛；重甲骑士握持带锥形枪身和护手的骑枪，保持枪身方向前送、沿原路收回，坐骑承重、缰绳和骑手随之联动；现代匕首兵以防护姿态蹬地短刺。武器保持固定长度，蓄力、接触与回收衔接实际命中时刻。

动画工坊集中预览所有部队、炮塔、弹道与命中、大招、地面效果、基地和昼夜星空。支持分类／时代筛选、搜索、阵营与动作切换、¼ 倍／½ 倍慢放、暂停、逐帧、时间轴回放及点击放大；恐龙与马可开启步态辅助线。攻击预览使用真实战斗模拟，倒拖时间轴会恢复对应帧。

战斗表现按兵器区分：箭矢随重力弧线转向并嵌入目标，枪弹、坦克炮与能量弹直射；投石留下碎屑和尘土，榴弹与火箭产生短促爆焰和烟尘。沸油以液流下落，落地后形成带蒸汽的油池；箭雨留下箭簇，轰炸弹从飞机释放后继续向前下落。动画不改变伤害、射程和命中时序。

五代基地拥有不同的整体轮廓：原始时代是不规则巨岩、兽骨洞口和兽皮帐篷；中世纪是高尖顶与雉堞角楼；文艺复兴是赤陶屋顶和低矮星形棱堡；现代是宽体机库、卷帘门与扫描雷达；未来是开放式反应环、悬浮晶核和弯曲装甲翼。

炮位分别融入岩棚、城楼、斜面炮垒、屋顶指挥舱和装甲支臂；每次扩容增加连入主体的建筑结构，拆塔后保留炮座。受损细节与废墟也按时代区分。双方建筑朝向战场，手机上的模型与弹道同步缩放；动画工坊可直接对比五代基地。

昼夜每 120 秒对局时间循环一次，太阳、月亮、山峦与地面同步变化；星星以各自节奏闪烁。星空使用固定种子的二维分布，坐标按天空宽高归一化，窗口缩放和手机横竖屏切换时保持相对位置，不会因高度取余而排成直线。切换标签页、打开指挥手册或对局结束会暂停游戏，重开回到黎明。系统开启「减少动态效果」时，战场背景和模型动作保持静态；图鉴默认暂停，可手动播放。
