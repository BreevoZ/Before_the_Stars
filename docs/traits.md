# 兵种特性与平衡（v9）

## 购买与启用

文明火种花费 1 Legacy，立即解锁 1× / 2×；现代层的时间加速花费 16，解锁 3×。速度只影响每帧执行的固定步数，战斗步长仍为 1/60 秒。调试档位不变。基础自动招募是累计通关 2 次的免费里程碑，首次解锁默认关闭。

兵种主干每个时代 3 项，前一层至少买过 `TALENT_LAYER_REQUIREMENT = 1` 项才能买下一层；原始层需要文明火种。单节点价格为 2 / 4 / 8 / 16 / 32 Legacy。节点均在两轮之间购买，战斗特性使用新一轮的天赋快照；敌军和经典模式默认不获得这些特性。

未来层任意一项后可购买超级士兵计划（64），开启未来时代第四种部队。初始仅使用 32 距离、440 基础伤害的贴身激光短匕首，攻击间隔 0.55 秒；狙击激光枪（128，保留 `superRanged` ID）开启 1800 伤害、520 对兵／620 攻城射程的完全穿甲激光。锁定引导 1.1 秒、开火后冷却 2.4 秒；连线与收拢准星显示目标，丢失目标时取消并重新锁定，敌人贴身时取消引导切回匕首。匕首连击仍采用 0.55 秒间隔。武器数值集中在 `game-config.js:SUPER_WEAPONS`。精锐征召（128）改为计划的自动化子节点。Great Filter Bypasser 价格为 2²⁰，终局结算后可购买并播放升空演出，持久化抵达 VI 入口；轨道建设与战斗尚未实现。

## 扩展约定

- 每个注册项声明 `id`、适用 `units`、`hooks`、`state`。注册顺序就是同一单位的钩子执行顺序。
- `trait_<id>` 是默认关闭的布尔属性。天赋贡献玩家限定的 `override: true`；附加挑战来源随后可覆盖为 `false`，`explainStat()` 保留来源。即使额外来源开启敌方属性，钩子入口仍拒绝敌军执行玩家特性。
- 固定入口：接敌检测 `onEngage` → 每次发射／近战的 `beforeAttack` → 结算命中的 `onHit` → 阵亡清理前的 `onKill` / `onDeath`。`onEngage` 内的一次性动作由单位 `used` 状态保证仅触发一次。
- 命中钩子按攻击者、受击者、最近保护者依次执行；护甲与格挡后计算实际伤害。反击进入同一命中队列，并标记为次级攻击，避免格挡互相递归。格挡只接受显式 `melee` 命中，不能挡住炮弹爆炸。
- 钩子仅使用模拟上下文，不接触 DOM、Canvas、真实时间或定时器。额外攻击通过正常投射物／命中路径，治疗不能超过属性管线的生命上限。力场分担已经减伤后的伤害，不再重复减伤。
- 投射物发射时保存伤害、穿透、跳弹、减速与火场参数；落点及次级弹读取原快照。后续进化、读档和加成栈变化不会追改已经发出的攻击。
- 单位 `traits` 的字段由注册表校验：一次性标记、格挡时钟、过载发射计数；临时减速时钟、动作计时、投射物和火场来源也进入 v9 schema。狙击的剩余／总引导时间及锁定单位 ID／基地也保存并校验；暂停和读档都不跳过引导，不重复开火。未知特性、错误兵种、非法类型／范围都会拒绝导入。
- `traitActivations` 是模拟观测量，按特性反馈事件累计，不影响战斗。火场落地、护盾受击或力场破裂也计为事件；不要把不同特性的计数直接当作强度排行。

15 项特性均在动画工坊的「兵种特性」分类中预览。`src/trait-scenarios.js` 使用真实战斗钩子与确定性检查点，支持倒拖、逐帧和慢放，同时供 Node 平衡脚本使用。表现沿用低饱和色块；减少动态效果保留静态提示，关闭运动残影。

## v8 → v9

退役的 Autobuyer 根节点从购买账本移除；拥有旧根的玩家获得 `talentGrants: ['spark']` 对应的免费文明火种，并通过 `automationRetained` 保留自动化资格。付过 1 Legacy 的退回 1，旧免费赠予退回 0，`totalLegacy` 不变。已购精锐征召的旧玩家免费获得计划前置，不追收费用。存档版本迁移不触发结算、重建或资源补发。

永久 `settings.speed` 初始为 1，必须属于已解锁的速度档位；偏好跨轮次保存。自动招募是否解锁从有效循环数和历史保留标记推导。

## 可重复平衡扫描

```bash
mkdir -p sim/results
npm run sim:traits -- sim/results/traits.csv
# 可选：只重测指定行为
node sim/traits.js sim/results/parry.csv parry
```

沿用 `sim/grid.example.json` 的 18 个组合：生产档案 1 / 3 / 5 × 难度 0 / 1 / 2 × 编队比例 2:2:1 / 1:1:3。共 15 × 18 = **270 对（540 次完整文明模拟）**。每对具有相同的时代前置和配置，只相差待测的一个天赋。自动化里程碑使用 `completedCycles: 10`；不施放大招，不加入额外种子或随机规则。

再执行 15 对固定战斗场景，检查实际伤害、治疗、保护或位移差异。这些场景与工坊共用，能保证齐射的三名火枪手、霰弹的近距离集群等条件出现。它们用于行为验收，不替代完整文明网格。

CSV 的 `reduction_percent` 只在前后均通关时计算 `(原用时 - 新用时) / 原用时`；失败／超时保留原结果，百分比留空，不用失败时长伪造提速。`scene_health_delta` 为对齐单位 ID 后的生命绝对差之和，含治疗／伤害转移；`scene_position_delta` 为位置绝对差之和，并不代表所有差异都直接提高输出。脚本在场景无触发／无可测变化，或任一通关对照提速超过 25% 时返回失败。
