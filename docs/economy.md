# 地表文明：遗产经济（v12）

价格与倍率集中在 `progression-config.js` 的 `LEGACY_ECONOMY`、`TALENT_PRICES` 和 `CHALLENGE`。

## 一条原则

**指数增长来自远征深度，不来自购买的倍率。** 每深入一层余烬，终局遗产 ×2；购买的倍率只修剪曲线。价格必须比效果涨得快，否则每一级的回本时间不变，玩家就会陷入「每两轮买一级」的节拍器，战斗也不再影响进度。

```
终局遗产 = floor( 1 × 1.5 ^ 遗产保存等级 × 2 ^ 远征深度 )
```

| 深度 | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 遗产（保存满级 ×3.375） | 3 | 6 | 13 | 27 | 54 | 108 |

## 价格

| 进度 | 单项价格 |
| --- | --- |
| 文明火种 | 1 |
| 原始 → 中世纪 → 文艺复兴 → 现代 → 未来 | 2 → 4 → 8 → 16 → 32 |
| 超级士兵计划 → 狙击激光枪／精锐征召 | 64 → 128 |
| 遗产保存 1–3 级 | 4 → 16 → 64（每级 ×4 价格，×1.5 效果） |
| 余烬远征 | 4 |
| 遗产生产机 | 16 |
| 平行档案 1–3 级 | 64 → 256 → 1,024 |
| 回响加速 1–3 级 | 32 → 128 → 512 |
| 存续协议 | 500 |

**遗产保存的回本时间逐级变长**（以深度 5 计）：0.25 轮 → 0.67 轮 → 1.78 轮。这是价格曲线必须满足的性质，`npm test` 会检查它。

## 余烬远征

每深入一层，敌方的起始金币、收入、生命、伤害、基地生命与经验奖励全部 ×1.12（`CHALLENGE`）。旧存档与旧的进行中文明沿用当初的 1.35／1.25／1.2，由 `HISTORICAL_CHALLENGE` 固定。

以目前的天赋上限实测：**全买满的阵容大约能通关到第 5 层**，更深的层作为后续内容的余量保留。`存续协议`因此要求「通关第 5 层」，价格 500 约等于该深度的 5 轮收益。

## 遗产生产机

- 交战中按时间线性积累，**本轮上限 = 终局遗产 × 产能占比**（25% / 50% / 75% / 100%，由平行档案提升）。
- 填满上限需要 600 模拟秒，回响加速每级减半。
- **只有走到终局才会入账**：战败、放弃或超时都不发放，所以既不能靠拖时间刷，也不能靠潜入打不过的深层刷。
- 累计产出单独记录，不增加通关次数。

## 实测节奏

`node sim/economy.js [轮数]` 会用真实战斗模拟整条地表曲线：它按一个合理的购买顺序花钱，赢了就往下一层探，输了就退回并在买到新东西后重试。技术托管与防御工程之前的轮次由玩家手动操作，模型按 300 秒一轮的通关计。

最近一次结果（`sim/results/economy.json`）：

| 指标 | 值 |
| --- | --- |
| 启航轮次 | 第 157 轮 |
| 模拟时间合计 | 9.3 小时（2× / 3× 速度下实际更短） |
| 最深余烬 | 第 5 层 |
| 单轮收益曲线 | 1 → 3 → 9 → 19 → 38 → 189 |

这些仍是原型值。战役结构（敌人在单场战斗内自行进化，导致五场战役被压缩成 1–2 场）尚未修正，修正后需要重跑本文的全部数字。

## 存档

v12 退役了八级的遗产保存与文明传承分支。退役的等级通过账本退款：删除支付记录，余额自然回到玩家手里。**进行中的文明保持它开始时的合约**（`run.legacyRules`），包括已结算的终局奖励和当时的余烬倍率；重建后才使用新规则。历史价格由 `save-history.js` 的 `HISTORICAL_TALENTS[10]`、`[11]` 固定，账本仍按实际支付价校验。
