# Before the Stars

一款受《Age of War》启发的极简网页策略游戏。从原始时代推进到未来时代，训练部队、部署炮塔，摧毁敌方基地。

原生 JavaScript、Canvas 2D 与 CSS，无需安装依赖或构建。场景、部队、炮塔与图标均由代码绘制。

## 本地运行

在项目目录启动静态服务器：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8000>。项目使用 ES modules，需要通过 HTTP 访问。

- 默认增量模式：`/`（原入口 `/?mode=incremental` 仍可使用）
- 经典模式：`/?mode=classic`，入口在战场底部
- 快速调试：`/?mode=debug`，入口在战场底部，使用独立存档
- 兵种图鉴：`/units.html`
- 炮塔图鉴：`/turrets.html`
- 动画工坊：`/animations.html`（无需开局）
- 浏览器测试：`/tests/`

## 玩法

默认入口为**增量模式**。经典模式保留在战场底部的小字入口中，保留经典战斗规则，不读取或应用永久增益。两种模式复用同一战斗模拟、部队、炮塔、图鉴和渲染；默认 `createGame()` 仍保持经典战斗规则。

左侧绿灰色为我方，右侧土橙色为电脑。部队自动前进、攻击射程内的敌军，再攻击基地。摧毁敌方基地获胜；同一模拟帧双方基地同时被摧毁为平局。

| 操作 | 方法 |
| --- | --- |
| 训练部队 | 点击部队卡，或按 `1` / `2` / `3`；未来时代另有 `4` 超级士兵 |
| 暂停／继续 | `空格` 或顶部暂停按钮；瞄准时空格也只暂停，长按不反复切换 |
| 取消训练 | 点击队列中的订单，退还原价 |
| 时代进化 | 经验达标后点击上箭头，或按 `E` |
| 建造炮塔 | 先选空炮位，再点炮塔卡；`T` 建造第一种炮塔 |
| 扩容／拆塔 | `+` 购买炮位；选中已有炮塔后点击拆除，返还原价一半 |
| 释放大招 | 点击大招或按 `Q`；攻击技能再点击战场选点，治疗直接施放 |
| 键盘瞄准 | 左右方向键移动落点，`Enter` 确认，`Esc` 取消 |
| 查看资料 | 悬停卡片，或打开 `?` 指挥手册、兵种／炮塔图鉴 |
| 重新开始 | 点击回转箭头或结算页的「再战一局」 |

主界面卡片只展示模型、价格与快捷键，名称和属性放在悬停提示中。手机可通过指挥手册和图鉴查看完整资料。图鉴支持动作、阵营和暂停控制。

### 经济与进化

- 双方起始 180 金币，原始时代每秒收入 7 金币；训练队列最多 5 位，每方兵力上限 16，包含训练中的订单。
- 击杀获得金币与完整经验；阵亡方获得该兵种 75% 的经验，向下取整。等待、建造、取消训练不会增加经验。
- 双方独立进化，玩家手动操作，电脑自动操作。进化不消耗金币和经验；基地增加生命上限与相同数额的当前生命，保留已受伤害。
- 旧兵、已付费订单、旧炮塔、飞行中的弹药和地面效果在进化后保留；购买列表切换到当前时代。
- 每方初始 1 个炮位，额外三个炮位分别需要 100、160、240 金币。

| 时代 | 累计经验门槛 | 基地生命上限 | 每秒收入 | 部队 |
| --- | ---: | ---: | ---: | --- |
| 原始 | 0 | 600 | 7 | 棍棒人、弹弓手、恐龙骑兵 |
| 中世纪 | 160 | 900 | 10 | 盾剑士、长弓手、重甲骑士 |
| 文艺复兴 | 480 | 1500 | 16 | 决斗士、火枪手、野战炮组 |
| 现代 | 1100 | 2400 | 24 | 匕首突击兵、自动步枪兵、主战坦克 |
| 未来 | 2200 | 3800 | 36 | 光刃战士、等离子射手、悬浮战争机器、超级士兵 |

### 部队与炮塔

部队通过装备轮廓和动作区分时代：兽皮、鸢盾、羽帽、钢盔、能量装甲依次演进。恐龙可咬击两个目标，骑士连续行进后获得冲锋伤害，盾剑士减免单体弹药，步枪兵三连点射；攻城单位可在较远距离轰击基地。

**超级士兵**参考原作的高价终局兵种定位，作为未来时代第四个手动招募选项（快捷键 `4`），经典、增量和调试模式均可使用。当前原型为 3000 金币、12 秒训练、6000 生命、32 护甲；远程每 0.55 秒发射 320 伤害的穿甲能量弹，目标进入 60 距离时改用 440 伤害的近身短打，攻城射程 540。外观参考原作未来射手一系的科幻步兵轮廓：普通步兵体型、深色紧身作战服、银灰贴身轻甲、分段护胫、半覆式头盔与细窄能量目镜，配紧凑能量短枪。以放松的待机姿态、短促点射和轻护手短打表现独行精锐的高爆发，维持低饱和、少量发光细节的极简风格。它仍占一名兵力并走普通训练／退款流程；为帮助玩家突破僵局，仅供玩家招募，电脑与基础自动招募仍使用原来的三个兵种。数值按本作经济重新设计，后续可继续试玩调整。

炮塔仅攻击射程内的敌方部队，每个炮位独立瞄准、装填和开火。三种同代炮塔各有用途：

| 时代 | 炮塔 | 机制与动作 |
| --- | --- | --- |
| 原始 | 弹石器、自动蛋塔、原始投石机 | 弹力抛石、快速抛蛋、巨石范围砸击；弦回弹、料斗振动与投掷臂回收 |
| 中世纪 | 重型投石机、火焰投石机、沸油锅 | 配重投石、持续燃烧、近城烫伤减速；火弹装填与油锅倾倒 |
| 文艺复兴 | 轻型加农炮、重型加农炮、爆破加农炮 | 快速直射、完全穿甲重弹、范围榴弹；炮管后坐与复位 |
| 现代 | 单管炮塔、双管炮塔、火箭发射塔 | 稳定点射、双管交替、火箭范围轰炸；跟踪瞄准、独立后坐与导轨装填 |
| 未来 | 钛金射击塔、激光炮塔、离子射线塔 | 动能贯穿、高频穿甲脉冲、充能射线；轨道放电与充能翼展开 |

特殊规则：

- **火焰与沸油**：落点留下持续 2.4 秒的敌方伤害区域。火焰每 0.4 秒造成 6 点伤害；沸油每 0.4 秒造成 5 点伤害，并将区域内敌人的移动速度降至 55%。持续伤害无视护甲，不伤友军和基地；离开油区即恢复移速。
- **双管交替**：每轮两发，各造成 62 点基础伤害，间隔 0.16 秒。目标死亡或离开射程时取消余下射击，不转移到新目标。
- **贯穿**：钛金弹额外命中原目标后方 90 距离内的一名敌人，伤害为 60%；离子射线充能 0.65 秒后，额外命中后方 130 距离内的两人，伤害为 65%。贯穿不能超出炮塔射程，离子充能在目标丢失时取消。
- **拆除与进化**：已发射弹药、已落地火焰与沸油继续生效；拆塔会取消尚未发射的连射和充能。进化保留旧炮塔的连射、充能与冷却。

完整价格、射程、伤害和冷却直接从配置生成到图鉴与悬停提示，避免文档与游戏数值重复维护。

### 大招与电脑对手

五个时代分别拥有陨星天降、箭雨齐射、复苏之光、轰炸空袭与轨道打击。大招冷却独立于进化；进化不能重置冷却，也不会取消已释放的大招。

电脑遵守相同的金币、训练和进化规则。通常混合推进；面对炮塔会积攒资金组织攻城波次，基地受威胁时优先防守。电脑没有大招。纯造塔可以争取时间，但不能阻止电脑通过阵亡经验进化。

## M1：地表文明的重建循环

直接打开首页即可进入，也兼容 `/?mode=incremental`。**首次击败未来时代敌方基地、完成有效循环后**，顶部才会出现「档案」，之后重建与刷新均保留入口。普通战役胜利、仅进化至未来、战败和平局不会解锁。首次通关前战败可直接从原始时代重试。`空格`／顶部「暂停」停止战斗；打开档案、存档或手册、隐藏页面同样暂停。

1. **普通战役胜利**：被击败的敌人尚未到未来时代时，点击「继续文明进程」。仍属同一文明，新敌人从刚被击败敌人的时代 +1 开始。我方金币、经验、时代、炮位和炮塔保留，基地按当前时代恢复满血，未完成订单按实际支付价格退款。场上部队、弹药、地面区域和技能效果清除；大招及炮塔冷却保留，未发出的连射和充能取消。玩家仍须手动进化。
2. **文明终局**：击败**未来时代敌方基地**后，战争获胜但文明毁灭。每轮有效完成仅计入 1 次循环、获得 1 点文明遗产。仅自己进化到未来不算通关，普通胜利、战败、平局和主动重开均无遗产。
3. **留下档案**：毁灭画面可立即跳过，奖励在进入结算时一次性入账，不依赖动画。打开「查看遗产与重建」，购买永久升级或配置自动招募。
4. **重建文明**：清除本轮金币、经验、时代、军队、订单、炮位与炮塔，从原始时代开始；保留循环次数、遗产、永久升级和自动招募偏好。战败也可保留永久进度重试。主动放弃未完成文明须确认；重开不等于清空存档。

### 永久升级与自动招募

仅在毁灭或战败后、下一轮开始前购买，新一轮使用升级等级快照，读档不会重复乘倍率。

| 档案 | 每级效果 | 最高等级 | 逐级价格（文明遗产） |
| --- | --- | --- | --- |
| 生产档案 | 被动金币收入 × `1.5 ^ 等级` | 5 | 1、2、4、8、16 |
| 战争档案 | 玩家战斗经验 × `1.25 ^ 等级` | 5 | 1、2、4、8、16 |

生产档案不改变击杀金币。经验先计算经典基础奖励：击杀完整经验，阵亡为 `floor(基础经验 × 0.75)`；再对每笔玩家奖励计算 `floor(经典奖励 × 战争档案倍率)`。敌军、经典模式和图鉴基础属性不受影响。收入提示、进化提示和文明档案显示同一份本轮倍率。

首次有效循环后**免费永久解锁自动招募**，首次默认关闭。玩家选择「前排 / 远程 / 重型」位置，每 0.25 秒模拟时间尝试正常付费招募一次；进化后自动解析新时代理应对应的兵种。仍遵守金币、训练队列及兵力上限。暂停、页面隐藏、胜利或文明结算时停止，不积累离线尝试。

原型假设集中在 `src/progression-config.js`：地表终点明确固定为 age 5；新敌人的初始金币按原始至未来为 180 / 300 / 480 / 720 / 1080，经验为对应时代门槛，基地满血、一个空炮位。升级与自动化数值均待试玩调整。M1 不包含 Bypasser、Orbital 文明层或第二层重置；原有未来时代「轨道打击」战斗技能保留。

### 存档与恢复

增量模式使用带版本号的浏览器本地存档（当前版本 1），同时保存永久数据、本轮结算标记和完整战斗状态，包括订单、部队、弹药、地面效果、技能、电脑状态及冷却。刷新可恢复普通胜利或毁灭结算页，不重复退款、发奖或叠加倍率。

- 每 10 秒模拟时间自动保存；结算、继续冲突、购买升级、设置自动招募、重建及隐藏／关闭页面时立即保存。关闭期间**没有离线收益，也不推进战斗**。
- 战场底部「存档」从开局即可使用；解锁档案后也可从其中进入。该入口提供手动保存、JSON 导出、文件／文字导入和恢复上一份有效备份。导入先校验版本、字段类型、数值范围与状态一致性，再确认替换。
- 损坏或未知版本的原存档会被保护，自动保存停止覆盖；可恢复备份、导入有效存档或确认清空。此时仍可试玩、导出当前内存进度。
- 存储被禁用或空间不足时显示提示，游戏继续运行；请导出保存。另一标签页写入存档后，旧页面也会停止覆盖并提示刷新。
- 「清空全部进度」须明确确认，会删除永久进度及本地备份。导出的文件不受影响。存档按浏览器和站点地址隔离，切换端口或浏览器需导出再导入。
- 浏览器崩溃或强制结束可能丢失最近一次自动保存之后的操作；关闭事件只是额外保存机会，不替代定期保存。

### 验证完整循环

正常试玩：进入增量模式 → 出兵、手动进化并获胜 → 若敌人尚未到未来则继续文明 → 摧毁未来敌方基地 → 查看遗产 → 购买生产档案 → 启用自动招募并选择位置 → 重建。此时回到原始时代，收入显示 `+10.5/s`；首次购买后遗产余额为 0。刷新后升级与自动招募设置仍保留。

自动验证：启动静态服务器后打开 `/tests/`，等待页面顶部显示通过数量及 0 failed。除原有战斗、界面和动画回归，还包含完整正常付费文明循环、重复结算／退款保护、倍率隔离、自动招募限制、存档往返及损坏保护。增量 UI 测试使用独立内存存储和末战场景，通过真实伤害触发结算，实际操作继续、购买、重建，再重新加载验证；不依赖生产调试接口。

### 快速调试

打开 `/?mode=debug`，或点击战场底部「快速调试」。顶部会显示「调试 · 独立存档」工具栏。

- 默认 **10 倍模拟速度**，可选 1／5／10／20 倍。训练、行军、战斗、冷却和自动招募一起加速，仍使用固定步长；空格或按钮暂停、打开档案／存档／手册、隐藏页面均停止推进。
- 每个新文明额外提供 **10000 金币**，经验补足到可手动进化至未来；仍需点击进化或按 `E`，不会自动进化。读档不重复补发资源。「补充资源」可再次添加测试金币并补足经验。
- 「战役胜利」摧毁当前敌方基地；「终局结算」将敌人推进至未来后摧毁基地；「战败」摧毁我方基地。三者都走现有流程状态机，方便快速检查继续冲突、遗产、升级与重建。
- 调试存档和备份与正式增量模式完全分开，导出文件带 `debug` 标识，正式模式拒绝导入调试存档；清空调试进度不会清空正式进度。速度设置会随调试存档保留。

测试超级士兵：在调试模式连续按四次 `E` 进化至未来，按 `4` 训练；空格暂停检查。动画工坊搜索「超级士兵」可分别预览行军、射击与近身短打。

最快验证：点「终局结算」→「查看遗产与重建」→ 购买生产档案 → 启用自动招募 →「重建文明」。新文明显示 `+10.5/s`，此数值按**模拟秒**计算；10 倍速度下每现实秒会推进约 10 个模拟秒。

## 画面与动画

低饱和色块、无粗描边轮廓和少量明暗分面统一场景、部队与炮塔。战场、建造／招募卡和动态图鉴使用同一套模型。

恐龙采用双足承重，马采用四足错相步态。支撑脚按实际行进距离贴地，摆腿时抬脚。马的前腿分为肘、腕、球节与蹄，承重时较直、抬蹄时折收；后腿的膝关节向前、飞节向后，分别求解，避免反关节。攻击时恐龙探颈咬合、骑手同步送出石矛；重甲骑士握持带锥形枪身和护手的骑枪，保持枪身方向前送、沿原路收回，坐骑承重、缰绳和骑手随之联动；现代匕首兵以防护姿态蹬地短刺。武器保持固定长度，蓄力、接触与回收衔接实际命中时刻。

动画工坊集中预览所有部队、炮塔、弹道与命中、大招、地面效果、基地和昼夜星空。支持分类／时代筛选、搜索、阵营与动作切换、¼ 倍／½ 倍慢放、暂停、逐帧、时间轴回放及点击放大；恐龙与马可开启步态辅助线。攻击预览使用真实战斗模拟，倒拖时间轴会恢复对应帧。

战斗表现按兵器区分：箭矢随重力弧线转向并嵌入目标，枪弹、坦克炮与能量弹直射；投石留下碎屑和尘土，榴弹与火箭产生短促爆焰和烟尘。沸油以液流下落，落地后形成带蒸汽的油池；箭雨留下箭簇，轰炸弹从飞机释放后继续向前下落。动画不改变伤害、射程和命中时序。

五代基地拥有不同的整体轮廓：原始时代是不规则巨岩、兽骨洞口和兽皮帐篷；中世纪是高尖顶与雉堞角楼；文艺复兴是赤陶屋顶和低矮星形棱堡；现代是宽体机库、卷帘门与扫描雷达；未来是开放式反应环、悬浮晶核和弯曲装甲翼。

炮位分别融入岩棚、城楼、斜面炮垒、屋顶指挥舱和装甲支臂；每次扩容增加连入主体的建筑结构，拆塔后保留炮座。受损细节与废墟也按时代区分。双方建筑朝向战场，手机上的模型与弹道同步缩放；动画工坊可直接对比五代基地。

昼夜每 120 秒对局时间循环一次，太阳、月亮、山峦与地面同步变化；星星以各自节奏闪烁。切换标签页、打开指挥手册或对局结束会暂停游戏，重开回到黎明。系统开启「减少动态效果」时，战场背景和模型动作保持静态；图鉴默认暂停，可手动播放。
