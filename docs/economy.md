# 地表文明：遗产经济（v12）

价格与倍率集中在 `progression-config.js` 的 `LEGACY_ECONOMY`、`TALENT_PRICES` 和 `CHALLENGE`。

## 一条原则

**指数增长来自远征深度，不来自购买的倍率。** 每深入一层余烬，终局遗产 ×2；购买的倍率只修剪曲线。价格必须比效果涨得快，否则每一级的回本时间不变，玩家就会陷入「每两轮买一级」的节拍器，战斗也不再影响进度。

```
终局遗产 = floor( 1 × 2 ^ 遗产保存等级 × 2 ^ 远征深度 × 首次抵达 )
```

基数是 1，所以唯一不会被向下取整吃掉的倍率就是 ×2——遗产保存每一级都实打实地翻倍。首次通关某一层额外 ×3，重复刷旧层不再触发。

| 深度 | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 遗产（保存满级 ×16） | 16 | 32 | 64 | 128 | 256 | 512 |

## 开局三轮

| 轮 | 收益 | 买到 |
| ---: | ---: | --- |
| 1 | +1 | 文明火种（解锁 2× 速度） |
| 2 | +1 | 遗产保存 1 级（结算收益翻倍） |
| 3 | +2 | 余烬远征（开启深度） |

这三步是刻意固定的：每一轮都买得起一件东西，而且第二件就是"结算收益翻倍"。

## 价格

| 进度 | 单项价格 |
| --- | --- |
| 文明火种 | 1 |
| 原始 → 中世纪 → 文艺复兴 → 现代 → 未来 | 2 → 4 → 8 → 16 → 32 |
| 超级士兵计划 → 狙击激光枪／精锐征召 | 64 → 128 |
| 遗产保存 1–4 级 | 1 → 4 → 16 → 64（每级 ×4 价格，×2 效果） |
| 余烬远征 | 2 |
| 兵种层（原始→未来） | 4 → 8 → 16 → 32 → 64 |
| 遗产生产机 | 32 |
| 平行档案 1–3 级 | 128 → 512 → 2,048 |
| 回响加速 1–3 级 | 64 → 256 → 1,024 |
| 超级士兵计划 → 狙击激光枪 | 256 → 512 |
| 存续协议 | 10,000 |

**遗产保存的回本时间逐级变长**：价格每级 ×4、效果每级 ×2，所以回本轮数逐级翻倍。这是价格曲线必须满足的性质，`npm test` 会检查它。

## 余烬远征

每深入一层，敌方的起始金币、收入、生命、伤害、基地生命与经验奖励全部 ×1.12（`CHALLENGE`）。旧存档与旧的进行中文明沿用当初的 1.35／1.25／1.2，由 `HISTORICAL_CHALLENGE` 固定。

以目前的天赋上限实测：**全买满的阵容大约能通关到第 5 层**，更深的层作为后续内容的余量保留。`存续协议`因此要求「通关第 5 层」，价格 500 约等于该深度的 5 轮收益。

## 遗产生产机

- **即时入账**：产出的每一点遗产立刻进入余额，战斗中就能看到数字在涨；HUD 显示「每秒产出」。
- **本轮上限 = 终局遗产 × 产能占比**（50% / 100% / 150% / 200%，由平行档案提升），产满需要 240 模拟秒，回响加速每级减半（240 → 30）。
- 上限按**已经通关过的最深余烬**计算：潜入没打通过的深层，产量仍按已证明的深度算，也不含首通加成。所以刷深层没有收益。
- **额度属于这个文明，不属于单场尝试**：放弃或战败后重建会把已用额度带过去，只有真正走到终局才清零。所以反复开新轮刷产量也没有收益。
- 累计产出单独记录，不增加通关次数。

## 实测节奏

`node sim/economy.js [轮数]` 会用真实战斗模拟整条地表曲线：它按一个合理的购买顺序花钱，赢了就往下一层探，输了就退回并在买到新东西后重试。技术托管与防御工程之前的轮次由玩家手动操作，模型按 300 秒一轮的通关计。

模型里没有天赋的前几轮由玩家手动操作，模拟时按「等同于一个配置完整的自动购买」来打，账本只扣实际买过的东西。

最近一次结果（`sim/results/economy.json`）：

| 指标 | 值 |
| --- | --- |
| 启航轮次 | 第 31 轮 |
| 模拟时间合计 | 1.9 小时（2× / 3× 速度下实际更短） |
| 最深余烬 | 第 5 层 |
| 单轮收益曲线 | 1 → 2 → 12 → 48 → 192 → 960 → 3840 |

**当前地表阶段偏短，卡点是余烬天花板而不是钱**：全部买满的阵容大约只能通关到第 5 层，第 6 层打不过。后续第六时代和更强的天赋会把这个天花板往上推，届时存续协议的深度门槛和价格都要重调。

战役结构（敌人在单场战斗内自行进化，导致五场战役被压缩成 1–2 场）尚未修正，修正后需要重跑本文的全部数字。

## 存档

v12 退役了八级的遗产保存与文明传承分支。退役的等级通过账本退款：删除支付记录，余额自然回到玩家手里。**进行中的文明保持它开始时的合约**（`run.legacyRules`），包括已结算的终局奖励和当时的余烬倍率；重建后才使用新规则。历史价格由 `save-history.js` 的 `HISTORICAL_TALENTS[10]`、`[11]` 固定，账本仍按实际支付价校验。
