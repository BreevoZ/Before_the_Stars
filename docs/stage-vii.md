# VII · Interplanetary 设计草案

状态：构思中，尚未实现。本文记录已经定下的原则和待定问题，实现前再拆成分步计划。

## 定位

VII 是 VI 的**扩展**，不是新的一局。

- 进入 VII 不注入遗产、不重置任何东西。VI 的地球、星环、月面、天赋和余额全部保留并继续运行。
- 观测台从「地球 + 月球」扩展为**太阳系**：地球仍然是文明自发萌芽、战争、核毁灭的地方，其余行星是新的舞台。
- 货币仍然只有 Legacy。
- 远航协议仍是 VI 的终点，但它的含义从「带着文明离开」改为「方舟下水，打开行星际空间」。购买后 VII 的星图页开放，VI 继续照常运行。

## 地球是子宫

地球是太阳系里唯一会**自发**产生文明的地方。其他行星上的文明都来自地球：

- **文明转运**（VII 天赋）：把地球上正在发展的文明（或它的种子）装上方舟，在发射窗口打开时送往目标行星。
- 转运的文明保留时代、倾向、学说；在新环境里继续发展。
- 因此 VI 的核冬天—萌芽循环有了新的意义：地球不断产出「原料文明」，VII 负责把它们带出去。

## 行星分两类

### 可居住（殖民）

需要穹顶或改造才能居住，文明在上面照常战争、进化，产出 Legacy。环境改变文明的战斗方式（延续 VI 的文明倾向）：

| 行星 | 环境 | 对文明的影响（草案） |
| --- | --- | --- |
| 火星 | 稀薄、干冷，资源稀缺 | 收入降低、伤害提高：更好战 |
| 木卫二 | 冰下海洋 | 基地更坚固、进化更慢 |
| 土卫六 | 甲烷湖、极寒 | 部队生命更高、行动更慢 |

长期项目「**地球化改造**」逐步削弱环境惩罚。

### 不可居住（工业）

不播种文明，只建设施，产出 Legacy 或提供全局效果，延续月面家园的做法：

| 天体 | 用途（草案） |
| --- | --- |
| 水星 | 近日太阳能阵列：所有行星工业产能倍率 |
| 金星 | 高空浮空城采集大气：稳定 Legacy 产出，后期可改造 |
| 小行星带 | 采矿：方舟载量、转运次数上限 |
| 木星 | 气态燃料：缩短转运航程、放宽发射窗口 |
| 天王星／海王星 | 深空中继与观测站：通往 VIII 的前置 |

## 发射窗口

行星在各自轨道上公转（周期按比例缩短）。两颗行星位置合适时才开放转运窗口，窗口有持续时间和冷却。木星燃料可以放宽窗口。转运途中的方舟在太阳系图上可见。

## 越过过滤器（救）

殖民行星上的文明同样会走向核毁灭。VII 的核心新机制是**阻止它**：

- 一场战争双方都到达第五时代、即将分出胜负时，玩家可以出手（斡旋、切断反扑、接管核武；具体做法待定）。
- 成功：胜方成为**升格文明**，不再参与核毁灭循环，永久留在该行星，持续产出 Legacy，并解锁更高层的设施。
- 失败或不出手：照常核毁灭并结算，行星进入冬天、等待下一次转运。
- 地球上的文明**不能**被升格：地球是子宫，它的循环保持不变。

星际战争（升格文明之间的冲突）暂缓，后期再议。

## 计算量

VI 同时跑最多 4 场真实战斗已经接近上限，VII 不能让每颗行星都跑完整模拟。

- **地球（VI）**：保持现状，真实战斗。
- **殖民行星**：默认用**抽象战争模型**推进：时代、基地血量比例、经验、胜负按拟合过的公式（VI 情报网络的胜率模型）逐秒演化。
- **正在观看的那一场**：从抽象状态实例化一场真实战斗（时代、基地血量、金币、经验对齐），观看期间跑真实模拟；切走时折回抽象状态。
- 用无头模拟校准抽象模型：同样的初始条件下，两者的胜率、进化时间和经验收益在统计上一致，写成测试。

## 与 VIII · Stellar 的衔接

每个阶段把上一阶段的「单位」抽象成一个节点，计算量和界面复杂度都不会爆炸：

- VI：一颗行星，真实战斗。
- VII：一个恒星系，多颗行星；只有观看的战斗是真实的，其余抽象。
- VIII：多个恒星系；每个被殖民的恒星系本身压缩为一个「VII 摘要模型」（升格文明数、工业产能、转运节奏），不再逐场战争模拟。

VII 的终点天赋建在外太阳系（深空中继 → 星际方舟／日球层星门），打开 VIII 的星图。升格文明在 VIII 中成为新的「子宫」：它们可以在别的恒星系自发产生文明，就像 VII 里的地球。

## 天赋树

第三页星图，接在 VI 上方，**远航协议是 VII 的根**（与存续协议连接前两页的方式相同，继续上下翻页）。

- 金色主线：远航协议 → 火星穹顶 → 文明转运 → 第一个升格文明 → 深空中继 → 星际方舟（VII 终点）。
- 绿色分支（草案）：
  - **航行**：发射窗口、航速、方舟载量、燃料。
  - **行星工业**：水星、金星、小行星带、木星、外行星设施。
  - **殖民与升格**：穹顶、地球化改造、环境适应、斡旋手段。

## 待定

1. 升格的具体操作（斡旋、切断反扑、接管核武各是什么交互）。
2. 行星公转周期、窗口长度与 VII 的整体时长（初步设想 60–90 分钟模拟时间）。
3. 殖民行星的核冬天是否与地球共享节奏，还是各自独立。
4. 太阳系观测台的界面：是否替换现有地球视图，还是作为观测窗的第三个页签（地球／月面／太阳系）。
