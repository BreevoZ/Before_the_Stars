# Before the Stars

一款受《Age of War》启发的极简网页策略游戏。从原始时代推进到未来时代，训练部队、部署炮塔，摧毁敌方基地。越过大过滤器后，在 VI 俯瞰重生的地表文明，挑动和干预战争，收获 Legacy 并开发月球。

原生 JavaScript、Canvas 2D 与 CSS，游戏无需安装依赖或构建。场景、部队、炮塔与图标均由代码绘制。开发用无头模拟与纯逻辑测试使用 Node 24+。大数计算使用仓库内固定版本的 MIT 库 break_infinity.js 2.2.0，无需 npm 安装或运行时 CDN。

## 本地运行

在项目目录启动静态服务器：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8000>。项目使用 ES modules，需要通过 HTTP 访问。

- 默认增量模式：`/`（原入口 `/?mode=incremental` 仍可使用）
- 经典模式：`/?mode=classic`，入口在战场底部
- 快速调试：`/?mode=debug`，入口在战场底部，使用独立存档；顶部或星图的「调整遗产」可直接设置余额（如 `128`、`1e6`），回车应用。调试账目单独保存，不伪造通关或远征深度。
- 兵种图鉴：`/units.html`
- 炮塔图鉴：`/turrets.html`
- 动画工坊：`/animations.html`（无需开局）
- 轨道独立试玩：`/tests/orbital-playground.html`（直接测试 VI，不修改正式存档）
- 浏览器测试：`/tests/`

### 战役补给

击败尚未到未来时代的敌人后，点击「继续文明进程」领取一次补给：金币为下一敌方时代基础起始金币的 75%，经验为距离该时代进化门槛所缺经验的 50%（向下取整）。胜利页显示准确数额；这笔补给不受击杀奖励倍率影响，也不会自动进化。原资产保留、订单退款和基地满血规则不变，重复点击或刷新不会多领。

增量模式中，超级士兵在购买「超级士兵计划」并重建生效后，才出现在未来时代的招募与帮助选项中；经典模式保留原有第四兵种。

### Node 测试与无头模拟

安装 Node 24 或更高版本后，在项目根目录直接运行，无需 `npm install`：

```bash
npm test
npm run sim
npm run sim:orbital
mkdir -p sim/results
npm run sim:batch -- --out sim/results/scan.csv
npm run sim:traits -- sim/results/traits.csv
```

- `npm test`：Node 内置测试器运行共享的战斗、文明、自动化、存档、动画运动学用例，以及模拟器／CSV／命令行测试；失败时退出码为 1。
- `npm run sim`：读取 [sim/example.json](sim/example.json)，输出一次完整文明模拟的 JSON。指定自己的配置：`node sim/run.js path/to/run.json`。
- `npm run sim:batch`：读取 [sim/grid.example.json](sim/grid.example.json)，扫描生产等级 × 挑战等级 × 编队比例的 18 种组合。指定网格：`node sim/batch.js path/to/grid.json --out sim/results/scan.csv`。
- `npm run sim:traits`：沿用上述网格，对 15 项兵种天赋逐项做有／无对照，补充真实战斗场景；输出 CSV，未触发、无可测量场景效果或单项提速超过 25% 时退出码为 1。详见 [兵种特性与平衡](docs/traits.md)。
- 不传 `--out` 时 CSV 写到标准输出，进度写到标准错误；可用 `node sim/batch.js > sim/results/scan.csv` 重定向。`sim/results/` 已忽略，不上传批量结果。
- 浏览器回归仍在 `/tests/`，运行同一批纯逻辑用例及 Canvas、UI、键盘、响应式和刷新恢复测试。Node 不模拟 DOM，也不代替视觉验证。

模块入口是 [sim/simulate.js](sim/simulate.js) 的 `simulateRun({ talents, completedCycles, challengeLevel, automation, maxSeconds, bonuses })`，同步返回：

| 字段 | 含义 |
| --- | --- |
| `outcome` | `won` 通关、`lost` 战败、`draw` 平局、`timeout` 超时未完成 |
| `duration` | 本轮所有冲突的总模拟秒数，不是电脑执行耗时 |
| `battles` | 每场的 `number`、`duration`、`outcome`、敌方起始／结束时代和玩家结束时代；包含超时的未结束战斗 |
| `peakGold` | 我方金币余额峰值，包含起始资源与转场退款，按每帧及转场后采样 |
| `totalExperience` | 我方本轮累计获得的击杀与阵亡经验，包含战争档案增益 |
| `legacy` | 本轮终局奖励 + 实际战斗中生产的遗产；未通关时仅保留生产所得 |
| `settlementLegacy` / `producedLegacy` | 分别列出终局奖励和生产机所得 |
| `traitActivations` | 本轮各兵种特性的反馈事件计数，跨冲突累计；包含命中／吸收／破裂等事件 |

`talents` 使用 [src/talents.js](src/talents.js) 中的节点 ID → 等级，包含 `production` 和 `warfare`；省略的节点为 0。这是一套用于数值实验的已购天赋配置，不扣浏览器存档中的遗产。节点等级和前置必须有效，`challengeLevel > 0` 需要 `challenge` 天赋。难度范围 0–10。

`automation` 接受游戏现有设置，例如 `enabled`、`target`、`mode`、`weights`、`evolve`、`defense`、`elite`；省略项沿用游戏默认值，**默认关闭**，功能必须已由天赋解锁。`unlocked` 从 `completedCycles` 推导，不能手填。新模拟默认 0 次循环；测试自动招募需要显式设为至少 2，挑战深度不得超过已有循环数。调用 `simulateRun()` 不传配置，表示新文明无人操作，通常会战败；可从示例配置开始调整。

模拟固定使用游戏的 1/60 秒步长，复用真实 AI、付费招募、自动购买和文明结算。普通胜利自动继续同一文明，未来敌军基地被摧毁后结束。不自动重建，不额外施放技能或代替未解锁的自动进化；因此结果衡量配置的无人值守表现，不代表手动操作的胜率。默认时限为整轮 1800 模拟秒，可设 `maxSeconds`，最大 86400 秒，向下对齐完整帧。相同代码版本和配置会得到相同结果，随机 runId 不参与战斗或统计。

批量配置由 `base`（共用配置）和 `grid`（参数路径 → 候选值数组）组成，取笛卡尔积。例如 `"challengeLevel": [0, 1, 2]`、`"talents.production": [1, 3, 5]`、`"automation.weights": [[2, 2, 1], [1, 1, 3]]`。每个组合先校验，缺前置或非法设置会报出行号，不静默修正；单批最多 10000 组。CSV 包含扫描参数、胜负、总时长、逐场时长、金币峰值、经验、遗产及完整配置 JSON，便于筛选与复现。所有组合验证和运行成功后才写入 `--out` 文件；该文件存在时会替换它。

### 统一属性管线

战斗、自动购买、操作按钮和属性提示共用 `stat(game, subject, key)` / `attributes(game, subject)`。`explainStat()` 返回基础值、加成来源与结果；升级和挑战只贡献 `{ target, type, value, source }` 数据。创建文明与继续冲突共用同一个入口，起始金币也由管线结算。

完整字段、加／乘／覆盖顺序、禁用规则和扩展示例见 [属性管线说明](docs/stats.md)。`simulateRun()` 现在可额外接收 `bonuses` 数组，在无头模拟中直接测试新学说、深度、里程碑或挑战限制；网格也可用 `bonuses` 轴比较多组规则。这些实验不会改变正式模式的默认数值。

### 大数支持

金币、经验、生命、伤害、护甲、造价、收入、Legacy 与相关加成统一通过 [quantity.js](src/quantity.js) 计算，支持 `1e400` 等超过原生 Number 上限的值。小数值保持原来的原生计算路径；时间、坐标、射程、等级和数量上限继续使用有界 Number。成长属性不再截断为 `1e9`，界面共用科学计数格式，血条仅使用 0–1 比例。

大数是近似计算，保留约 15 位有效数字，不能保证天文数量上的逐点加减。Legacy 当前仍按整数精确记账，沿用原型安全上限。大数接口、范围、取整、存档和扩展约定见 [数值维护说明](docs/quantities.md)。

```bash
# 使用真实战斗与自动购买验证 1e400 级别的完整文明
node sim/run.js sim/large.example.json
```

模拟器的大金币／大经验指标输出为规范字符串，小数值指标仍为 JSON number；CSV 保留大数文本。用电子表格打开时，应将这些列指定为文本，避免表格软件自行转换溢出。自动购买的预留金币支持输入 `1e400`，仍需已解锁后勤调度。

## 玩法

默认入口为**增量模式**。经典模式保留在战场底部的小字入口中，保留经典战斗规则，不读取或应用永久增益。两种模式复用同一战斗模拟、部队、炮塔、图鉴和渲染；默认 `createGame()` 仍保持经典战斗规则。

左侧绿灰色为我方，右侧土橙色为电脑。部队自动前进、攻击射程内的敌军，再攻击基地。摧毁敌方基地获胜；同一模拟帧双方基地同时被摧毁为平局。

| 操作 | 方法 |
| --- | --- |
| 训练部队 | 点击部队卡，或按 `1` / `2` / `3`；未来时代另有 `4` 超级士兵 |
| 暂停／继续 | `空格` 或顶部暂停按钮；瞄准时空格也只暂停，长按不反复切换 |
| 游戏倍速 | 文明火种解锁后，按 `R` 或点顶部速度按钮；时间加速解锁最高 3× |
| 取消训练 | 点击队列中的订单，退还原价 |
| 时代进化 | 经验达标后点击上箭头，或按 `E` |
| 建造炮塔 | 先选空炮位，再点炮塔卡；`T` 建造第一种炮塔 |
| 扩容／拆塔 | `+` 购买炮位；选中已有炮塔后点击拆除，返还原价一半 |
| 释放大招 | 点击大招或按 `Q`；攻击技能再点击战场选点，治疗直接施放 |
| 键盘瞄准 | 左右方向键移动落点，`Enter` 确认，`Esc` 取消 |
| 查看资料 | 悬停卡片，或打开 `?` 指挥手册、兵种／炮塔图鉴 |
| 重新开始 | 点击回转箭头或结算页的「再战一局」 |

主界面卡片只展示模型、价格与快捷键，名称和属性放在悬停提示中。手机可通过指挥手册和图鉴查看完整资料。图鉴支持动作、阵营和暂停控制。

### 经济与进化

- 双方起始 180 金币，原始时代每秒收入 7 金币；训练队列最多 5 位，每方兵力上限 16，包含训练中的订单。
- 击杀获得金币与完整经验；阵亡方获得该兵种 75% 的经验，向下取整。等待、建造、取消训练不会增加经验。
- 双方独立进化，玩家手动操作，电脑自动操作。进化不消耗金币和经验；基地增加生命上限与相同数额的当前生命，保留已受伤害。
- 旧兵、已付费订单、旧炮塔、飞行中的弹药和地面效果在进化后保留；购买列表切换到当前时代。
- 每方初始 1 个炮位，额外三个炮位分别需要 100、160、240 金币。

| 时代 | 累计经验门槛 | 基地生命上限 | 每秒收入 | 部队 |
| --- | ---: | ---: | ---: | --- |
| 原始 | 0 | 600 | 7 | 棍棒人、弹弓手、恐龙骑兵 |
| 中世纪 | 160 | 900 | 10 | 盾剑士、长弓手、重甲骑士 |
| 文艺复兴 | 480 | 1500 | 16 | 决斗士、火枪手、野战炮组 |
| 现代 | 1100 | 2400 | 24 | 匕首突击兵、自动步枪兵、主战坦克 |
| 未来 | 2200 | 3800 | 36 | 光刃战士、等离子射手、悬浮战争机器、超级士兵 |

### 部队与炮塔

部队通过装备轮廓和动作区分时代：兽皮、鸢盾、羽帽、钢盔、能量装甲依次演进。恐龙可咬击两个目标，骑士连续行进后获得冲锋伤害，盾剑士减免单体弹药，步枪兵三连点射；攻城单位可在较远距离轰击基地。

**超级士兵**是未来时代第四个玩家招募选项（快捷键 `4`）。增量与调试模式需要天赋「超级士兵计划」，经典模式直接保留原有可用规则。原型为 3000 金币、12 秒训练、6000 生命、32 护甲；初始以短激光匕首进行 32 距离的贴身刺击，造成 440 穿甲伤害，间隔 0.55 秒。后续「狙击激光枪」解锁 520 对兵／620 攻城射程、1800 单发穿甲伤害；先以连线和收拢准星锁定 1.1 秒，开火后冷却 2.4 秒。目标死亡或超出射程会取消引导，新目标必须重新锁定；**敌人进入 120 距离即视为贴身**，立即取消引导、收枪并走进 32 距离用匕首连刺，敌人被清掉后恢复狙击。经典模式仍保留原有 320 伤害的远程点射。模型维持普通步兵体型，头部、躯干和四肢由轻甲包裹，使用窄目镜与少量能量光。仍按正常经济、队列和兵力上限招募；「精锐征召」是计划的自动化子节点。

炮塔仅攻击射程内的敌方部队，每个炮位独立瞄准、装填和开火。三种同代炮塔各有用途：

| 时代 | 炮塔 | 机制与动作 |
| --- | --- | --- |
| 原始 | 弹石器、自动蛋塔、原始投石机 | 弹力抛石、快速抛蛋、巨石范围砸击；弦回弹、料斗振动与投掷臂回收 |
| 中世纪 | 重型投石机、火焰投石机、沸油锅 | 配重投石、持续燃烧、近城烫伤减速；火弹装填与油锅倾倒 |
| 文艺复兴 | 轻型加农炮、重型加农炮、爆破加农炮 | 快速直射、完全穿甲重弹、范围榴弹；炮管后坐与复位 |
| 现代 | 单管炮塔、双管炮塔、火箭发射塔 | 稳定点射、双管交替、火箭范围轰炸；跟踪瞄准、独立后坐与导轨装填 |
| 未来 | 钛金射击塔、激光炮塔、离子射线塔 | 动能贯穿、高频穿甲脉冲、充能射线；轨道放电与充能翼展开 |

特殊规则：

- **火焰与沸油**：落点留下持续 2.4 秒的敌方伤害区域。火焰每 0.4 秒造成 6 点伤害；沸油每 0.4 秒造成 5 点伤害，并将区域内敌人的移动速度降至 55%。持续伤害无视护甲，不伤友军和基地；离开油区即恢复移速。
- **双管交替**：每轮两发，各造成 62 点基础伤害，间隔 0.16 秒。目标死亡或离开射程时取消余下射击，不转移到新目标。
- **贯穿**：钛金弹额外命中原目标后方 90 距离内的一名敌人，伤害为 60%；离子射线充能 0.65 秒后，额外命中后方 130 距离内的两人，伤害为 65%。贯穿不能超出炮塔射程，离子充能在目标丢失时取消。
- **拆除与进化**：已发射弹药、已落地火焰与沸油继续生效；拆塔会取消尚未发射的连射和充能。进化保留旧炮塔的连射、充能与冷却。

完整价格、射程、伤害和冷却直接从配置生成到图鉴与悬停提示，避免文档与游戏数值重复维护。

### 大招与电脑对手

五个时代分别拥有陨星天降、箭雨齐射、复苏之光、轰炸空袭与轨道打击。大招冷却独立于进化；进化不能重置冷却，也不会取消已释放的大招。

电脑遵守相同的金币、训练和进化规则。通常混合推进；面对炮塔会积攒资金组织攻城波次，基地受威胁时优先防守。电脑没有大招。纯造塔可以争取时间，但不能阻止电脑通过阵亡经验进化。

## M1：地表文明的重建循环

直接打开首页即可进入，也兼容 `/?mode=incremental`。**首次击败未来时代敌方基地、完成有效循环后**，顶部才会显示 Legacy 余额和「天赋树」「自动购买」入口，之后重建与刷新均保留入口。普通战役胜利、仅进化至未来、战败和平局不会解锁。首次通关前战败可直接从原始时代重试。`空格`／顶部「暂停」停止战斗；打开天赋树、自动购买、存档或手册、隐藏页面同样暂停。

1. **普通战役胜利**：被击败的敌人尚未到未来时代时，点击「继续文明进程」。仍属同一文明，新敌人从刚被击败敌人的时代 +1 开始。我方金币、经验、时代、炮位和炮塔保留，基地按当前时代恢复满血，未完成订单按实际支付价格退款。场上部队、弹药、地面区域和技能效果清除；大招及炮塔冷却保留，未发出的连射和充能取消。进化可手动进行，也可解锁「技术托管」后自动进行。
2. **文明终局**：默认击败**未来时代敌方基地**后，战争获胜但文明毁灭。每轮有效完成仅计入 1 次循环，基础获得 1 点文明遗产，可由本轮生效的遗产天赋与挑战难度提高。仅自己进化到未来不算通关，普通胜利、战败、平局和主动重开均无终局奖励；战斗中已由生产机产出的遗产保留。
   解锁「赶尽杀绝」并重建后，摧毁任意时代敌方基地即可完成本轮文明并正常结算遗产，不再进入后续冲突。该天赋不要求开启自动购买；败局和平局仍无终局奖励。
3. **回到文明星图**：终局结算后自动进入全屏文明界面。首次通关播放约 22 秒的连续转场：敌方基地陷落 → 超级士兵反扑与核导弹升空 → 世界毁灭 → 废墟静默 → 天赋星图缓缓浮现。可点「跳过演出」或按 Esc；页面隐藏或存档窗口打开时暂停演出。奖励已一次性入账，不参与演出判定；减少动态效果时直接显示废墟、结算说明与星图。后续循环保留简短转场。底部始终可以直接重建，解锁挑战后也可进入更高难度。刷新结算存档直接恢复星图，不重复播放演出或发奖。
4. **重建文明**：清除本轮金币、经验、时代、军队、订单、炮位与炮塔，从原始时代开始；保留循环次数、遗产、永久升级和自动招募偏好。战败也可保留永久进度重试。主动放弃未完成文明须确认；重开不等于清空存档。

### 天赋树与自动购买

**首次有效通关后**，战场上方常驻显示 Legacy 余额，并提供独立的「天赋树」和「自动购买」入口。天赋界面是全屏的**文明星图**，底部根节点为 **文明火种（1 Legacy）**，解锁 1× / 2× 速度。主干从下向上经过原始、中世纪、文艺复兴、现代、未来五层，每层三个兵种天赋；自动化在左侧，文明增益和遗产收益在右侧，所有节点位于同一张星图，没有分支分页。SVG 曲线连接真实购买前置，主干较粗，已解锁路径点亮；手机保留至少 56px 的节点尺寸，先定位到根节点，上下探索时代，左右滑动浏览侧枝。Autobuyer 的开关与设置保留在独立界面。已有生产、战争档案保留已付价格和等级，作为文明增益分支。所有天赋仅在毁灭或战败后、下一轮开始前用 Legacy 购买；速度解锁随永久设置生效，其余战斗效果在新一轮保存等级快照，读档不会重复应用效果，结算后购买也不会追补本轮遗产。节点展示前置、当前与下一级效果、价格及锁定原因。文明增益仅作用于我方；经典模式不受天赋或挑战影响。

星图交互：

- 普通天赋为 58–64px 六边形，关键天赋为更大的圆形光晕节点，专精为菱形；图标用 SVG 绘制，废墟复用战场基地模型。
- 节点直接显示等级点（如 `●●○`）与下一级价格。前置满足且买得起时呼吸发光，未满足前置或遗产不足时压暗。
- 鼠标悬停或点击、键盘聚焦节点后出现详情浮层，显示**当前 → 下一级**对比。桌面贴近节点，手机为底部浮层；没有固定侧栏。
- 单击查看详情，**双击节点直接购买一级**，与详情购买按钮共用价格、前置、阶段与等级限制。`Tab`、方向键浏览节点，`Enter` 打开详情，再聚焦购买按钮并确认；`Esc` 先关闭详情，再返回战场。自动购买和存档仍有独立入口。
- 购买成功时连线流光、节点弹动、Legacy 数字跳动，余额立即显示真实扣费结果。减少动态效果设置会关闭演出、呼吸、流光和弹动，保留静态状态与文字反馈。
- 打开星图暂停战斗与自动购买，隐藏的战场 Canvas 也停止逐帧重绘。关闭后恢复原先的暂停状态。

| 档案 | 每级效果 | 最高等级 | 逐级价格（文明遗产） |
| --- | --- | --- | --- |
| 生产档案 | 被动金币收入 × `1.5 ^ 等级` | 5 | 2、4、8、16、32 |

生产档案不改变击杀金币。经验先计算经典基础奖励：击杀完整经验，阵亡为 `floor(基础经验 × 0.75)`；再对每笔玩家奖励计算 `floor(经典奖励 × 战争档案倍率)`。敌军、经典模式和图鉴基础属性不受影响。收入提示、进化提示和文明档案显示同一份本轮倍率。

**累计完成 2 次有效循环，免费解锁基础自动招募**，默认关闭。无需购买根节点；文明火种仍是天赋分支的前置。基础界面仅提供开关与目标；预算、编队、进化、防御和精锐设置在购买对应天赋后才出现。玩家选择「前排 / 远程 / 重型」位置，每 0.25 秒模拟时间尝试正常付费招募一次；进化后自动解析新时代理应对应的兵种。仍遵守金币、训练队列及兵力上限。暂停、页面隐藏、弹窗和文明结算时停止，不积累离线尝试；普通战役胜利可由「连续征战」继续。

天赋主干采用 **2 的幂次档位**（2 / 4 / 8 / 16 / 32…）。遗产的指数增长来自**远征深度**：每深入一层余烬，终局遗产 ×2；购买的倍率只做修剪，而且价格涨得比效果快（遗产保存每级价格 ×4、效果 ×2），所以没有一级是无脑必买。完整数值与实测曲线见 [遗产经济](docs/economy.md)，运行 `node sim/economy.js` 可重跑整条地表曲线。

**轨道启航**：购买先在同一存档中扣费并记录 `orbital` 阶段，随后星图缓缓淡出。36 艘火箭分批从废墟后方升起，残墙与地面实际遮挡舰体和尾焰。远处渐起暖色逆光，前景保持深色剪影，镜头随后上移进入星空，总长约 24 秒。抵达文字与操作区预先占位，按钮逐渐显现，不挤动标题。点击「跳过启航」或 `Esc` 可直接抵达；减少动态效果时显示静态抵达画面。中途刷新也直接恢复 VI，重播与回望星图不扣费、不发奖。抵达后点击「建立轨道家园」进入 VI；旧版已抵达的存档同样可以继续。进入家园前不推进轨道模拟；重播启航和回望星图会暂停地表战争与重生计时。

### VI · Orbital：文明的观测者

VI 继续使用 **Legacy 作为唯一玩家货币**，不再使用能源或排队建造。继承地表篇余额和速度偏好；`空格` 暂停、`R` 倍速。打开天赋树、存档、回望地表或隐藏页面时，战争与等待计时一起停止，没有离线收益。

1. **文明萌芽**：每轮从 8 个地球点位中随机产生 4–6 个原始文明。选择两个空闲文明，免费「挑起战争」；可以同时观察最多三场战争。
2. **战争进化**：双方 AI 通过正常招募、造塔、击杀与阵亡获得经验，复用第一阶段的战斗、兵种、动画和进化。没有按时间赠送科技。为适配双 AI 战争，双方被动金币 ×2.5（战术差异最多再 +5%）、战斗经验 ×2、基地生命 ×3，兵力上限 12、队列 4，均通过属性管线应用。
3. **战争遗产**：每累计 64 点真实战斗经验产生 1 Legacy，保留收益余数；技术馈赠不产生这份收益。消灭文明、主动收割和核毁灭另行结算。基础回收价值按时代为 `基础值 × 2^(时代−1)`：普通击败 64、主动收割 192、核毁灭 96，再乘轨道回收倍率。
4. **监控与干预**：购买「地面监控」后可观看真实战场。干预枝依次开放军备扶持（生命/伤害每次 ×1.25，最多 5 次）、科技升一代、科技倒退一代、直接毁灭收割。军备扶持初价 16，每次翻倍；进化初价 64、倒退初价 128，随目标时代翻倍。倒退会销毁该方超时代兵力、炮塔和训练订单；收割只结算一次。文明战斗中的金币属于它自己，轨道玩家所有支出都使用 Legacy。
5. **全球核毁灭**：一场战争的**双方都达到 V，且出现胜者**，所有现存文明一起毁灭、立即结算遗产。只有一方达到 V 或平局均不会触发。核冬天默认 60 秒，随后随机重新萌芽；「播种计划」每级将等待缩短为 75%。早期战争只消灭败方，胜方保留金币、经验和科技；若仅剩不足两个文明，每隔 30 秒会有新聚落萌芽，避免失去对手（同样受播种加速）。
6. **轨道天赋与月球**：独立全屏星图以「存续协议」为已点亮的根，地球在下、群星在上。监控干预、遗产回收、文明播种三条路线；「争端编织」可选择自动配对空闲文明。「遗产回收」三级分别达到 ×2 / ×4 / ×8。完成两次核毁灭、满足回收与播种前置后可花 16,384 Legacy 建立月球前哨，收益再 ×2；完成四次、满足前置后以 262,144 Legacy 解锁地月航行，标记 VI 完成。当前仍可继续观察地球，VII 尚未实现。

配置集中在 `src/orbital-config.js`。开战、干预、购买、核毁灭和新一轮萌芽立即保存。存档包含所有战争的部队、弹药、AI 状态、随机种子和核冬天进度，读档后确定性续跑。

**直接试玩**：启动静态服务器，打开 [`tests/orbital-playground.html`](./tests/orbital-playground.html)。可选「原始文明萌芽」「战争监控」「干预与收割」「核冬天」，支持随机种子、手机宽度和 1 / 5 / 10 / 20×。独立内存存档，刷新重置，不修改正式进度；正式入口仍是存续协议后的「建立轨道家园」。

**节奏验证**：`npm run sim:orbital` 执行种子 1 / 2 / 3 / 42 / 2026 的真实双 AI 战争，策略为及时配对、按固定优先级购买天赋，不使用科技干预。沿用正式游戏 `RULES.fixedStep = 1/60`。空钱包首次约 64–68 秒可购买监控，首次全球核毁灭约 5 分钟；四轮后完成 VI 分别约 **21.1 / 21.1 / 23.7 / 21.1 / 21.1 分钟**（1× 模拟时间）。目标是 20–30 分钟；人工决策、主动干预、携带余额和不同种子会改变节奏，尚需更多试玩调整。

### 地表经济与自动购买

自动购买与战场指令沿用星图的低饱和配色与细线。自动购买先显示总开关、运行状态和招募目标，预算、编队、进化与防御设置随天赋解锁；详细规则可展开阅读。开关支持键盘空格，手机表单保留触摸尺寸。招募卡采用无外框的灰绿分面预览，从实际模型生成，统一人物与炮塔的比例、居中和落脚线；价格保持可见，名称与属性保留在悬停提示及无障碍标签中。战场和图鉴继续使用原有模型配色。

速度偏好保存在永久设置中。`R` 或战斗 HUD 按钮循环 1× / 2× / 3×（按已购解锁）；只改变每帧执行的固定步数，步长仍为 `RULES.fixedStep = 1/60`。暂停、页面隐藏、弹窗照常冻结；调试模式仍使用原有 1 / 5 / 10 / 20 倍档位，`R` 不改变调试速度。

终局遗产统一计算为 `floor(2 ^ 遗产保存等级 × 2 ^ 远征深度 × 首次抵达加成)`。基数为 1，所以唯一不被取整吃掉的倍率就是 ×2；**首次通关某一层额外 ×3**，重复刷旧层不再触发。深度 5、保存满级为 512。开局三轮是刻意固定的：第 1 轮买文明火种（2× 速度），第 2 轮买遗产保存（收益翻倍），第 3 轮买余烬远征。历史已购买等级和对应价格保持不变；**进行中的文明沿用它开始时的规则**，重建后才换成新规则。

**遗产生产机**在地表文明中期开放（文艺复兴天赋层 + 遗产保存 1 级），花费 32 Legacy 解锁。它按时间持续产出遗产并**即时计入余额**，战斗中就能看到数字在涨，HUD 显示每模拟秒的产量。**本轮上限等于该轮终局遗产的一个比例**（初始 50%，平行档案升至 200%），产满需要 240 模拟秒，回响加速每级减半。上限按**已经通关过的最深余烬**计算，不含首通加成，所以潜入打不过的深层刷不到额外产量；已用额度在放弃或战败重建时带到下一轮，只有走到终局才清零，反复开新轮同样刷不出收益。累计产出另行记录，不增加通关次数。战场余额旁显示每秒产能，星图展示本轮已产、上限与累计所得。

生产仅在进行中的战斗推进，跟随正式／调试倍速；暂停、页面隐藏、弹窗、战斗结果及离线均不生产。剩余进度跨冲突、重建、失败和存档保留，不因刷新或重建额外产出。生产机和升级在新一轮生效；终局收益天赋与远征奖励不再乘到机器产出上，机器由独立两条天赋控制。所有产能、周期和开关仍通过属性管线结算，来源可查看。

数值集中在 `src/progression-config.js:LEGACY_ECONOMY` 和 `src/talents.js`，是首轮试玩默认值。重建储备只在开始新文明时发放；继续冲突只退款和发一次战役补给；生产档案只影响金币被动收入。

战场上方独立的「自动购买」窗口按已购天赋逐步提供以下功能，打开时暂停战斗：

- 基础开关和单一招募目标。后勤调度解锁预留金币、1–5 个队列上限、独立招募开关与购买优先级；其他高级功能随对应天赋解锁，默认关闭。基础默认预留 0 金币、正常 5 位队列；不开启高级功能时仅招募指定位置的部队。
- 编队比例每项 0–10，不能全为 0；0 表示不再购买该类。统计现有部队、旧时代部队与已付费订单，优先补充缺少的类型，不取消已有订单。精锐另设数量目标，优先储蓄补足。
- 显示当前待执行目标、预留外可用金币与等待原因。优先目标买不起时先存钱，不用便宜购买耗尽资金；队列或兵力已满时可处理防御。交替模式每次成功购买后让另一类先执行，调度顺序随存档保留。
- 炮塔按当前时代的第一／第二／第三种位置选择，可设 1–4 个目标炮位。扩容先存够炮位和炮塔全部费用；替换只针对旧时代炮塔，按原价一半返还，存够净支出与预留金额后才拆塔，不反复替换同代炮塔。
- 所有购买调用正常招募、建造、扩容和拆除流程，保留价格、队列、兵力及时代限制。预留金币与自动队列上限不限制手动操作。「战术火控」每 0.25 秒模拟时间检查大招：正常调用施放流程，遵守冷却和禁用项，空场不释放攻击技能，复苏之光等待受伤友军。
- 「连续征战」在普通战役胜利后的下一模拟步执行原有继续流程，补给、订单退款、恢复基地均只执行一次；暂停、隐藏页面或打开弹窗时等待。最终文明结算停止，重建仍由玩家选择。两个新开关均默认关闭，跨轮和刷新保留。
- 新自动化侧枝默认价格为 8 → 16 → 64 Legacy，沿用现有幂次档位，待试玩调整；赶尽杀绝属于文明规则，购买后下一轮生效。不会自动重建，也没有离线收益。

原型假设集中在 `src/progression-config.js`：地表终点明确固定为 age 5；新敌人的初始金币按原始至未来为 180 / 300 / 480 / 720 / 1080，经验为对应时代门槛，基地满血、一个空炮位。升级与自动化数值均待试玩调整。默认地表终局仍固定在第五时代，「赶尽杀绝」允许提前完成。存续协议现在接入 VI 的文明萌芽、双 AI 战争与月球开发；VI 复用地表战斗模拟与渲染，没有第二层重置。原有未来时代「轨道打击」战斗技能保留。

### 余烬远征

在遗产收益分支购买 **余烬远征**（前置：遗产保存 1 级，花费 2 Legacy）后，结算界面会出现两个选择：

- **重建文明 / 返回初生之地**：从原始时代开始常规难度，保留永久进度。
- **余烬远征 · 选关**：十关使用「纷争余烬」「铁旗时代」等名称，显示已通关、可挑战和未抵达状态。已通关关卡和下一关可选；先查看所选关卡的敌军倍率与实际遗产，再开始远征。仍从原始时代开始，使用新 runId 和最新天赋快照；本轮金币、经验、军队与防御清空。

通关奖励已经入账，选择挑战不需要押上已有遗产；战败、平局或主动放弃无终局奖励，已生产的遗产不会扣除。战败主按钮直接重试当前关卡；也可选已开放的其他关卡，或在星图返回常规文明。主动重开保持当前难度。完成文明终局（包括「赶尽杀绝」提前完成）后开放下一关，最深通关记录永久保留，回到常规文明也不丢失。普通战役胜利仍继续同一文明。重复通关不再发放首次抵达加成。第 10 关之后仍可自由重返已开放关卡。

倍率相对于常规文明计算，集中配置在 `src/progression-config.js` 的 `CHALLENGE`：

| 挑战等级 L | 倍率 |
| --- | --- |
| 敌军起始金币、被动收入 | `1.12 ^ L` |
| 敌军击杀与阵亡经验 | `1.12 ^ L` |
| 敌军部队生命、全部攻击伤害（含炮塔与地面效果） | `1.12 ^ L` |
| 敌军基地生命 | `1.12 ^ L` |
| 通关遗产 | `2 ^ L × 2 ^ 遗产保存等级`，首次通关该层再 ×3 |

起始金币向下取整，部队与基地生命四舍五入；经验沿用先算基础阵亡奖励、再乘倍率逐笔向下取整的规则。伤害在护甲与盾牌减伤前乘一次倍率，投射物读档不会二次加成。击杀金币、价格、兵力上限和训练时间不因挑战改变。图鉴继续展示基础属性。界面中的敌军倍率保留三位小数，模拟使用完整精度。

例如遗产保存 1 级：常规通关 +2，第 1 层首通 +12，第 2 层首通 +24（重复刷第 1 层为 +4）。以目前的天赋上限实测，全买满的阵容大约能通关到第 5 层，**存续协议**因此要求先通关第 5 层。这些倍率、价格和上限是待试玩调整的默认值；旧存档与进行中的旧文明沿用当初的 1.35／1.25／1.2 倍率。

### 存档与恢复

增量模式使用带版本号的本地存档（当前 **v16**），同时保存永久购买、循环次数、速度与自动购买偏好、本轮天赋快照、挑战、结算凭据和完整战斗状态。真实逐级支付账本也随永久数据保存；余额、自动招募解锁、加成栈和基地生命上限从输入推导；订单支付价格、投射物伤害与效果、单位特性状态保持原样。刷新不会推进离线战斗、重复奖励或重新乘倍率。

有效 v1–v13 存档逐版本迁移，原记录保留有效备份。v8 已购买 Autobuyer 的玩家免费获得文明火种（记录在 `talentGrants`），保留自动化解锁和偏好；旧根节点付过的 1 Legacy 原额退回，原先免费获赠则退 0，累计遗产不变。旧精锐征召玩家免费补齐超级士兵计划前置，不追收费用。迁移不重新结算，也不补发起始资源。v9 还验证一次性接敌标记、格挡时钟、过载计数、减速、狙击引导时钟／目标与发射快照。未知版本或损坏记录仍会阻止自动覆盖。

v13 → v14 保留原有战场、结算标记、实际支付账本和自动化设置，新增天赋等级为 0，自动大招和连续征战开关默认关闭。调试余额由「累计遗产 + 调试调整 − 实际支付」推导，调整余额不篡改奖励历史或通关次数；正式存档拒绝调试调整字段。

v15 → v16 将旧版轨道建设改为战争观测：保留已赚 Legacy 与地表永久进度，旧设施和在建工程的 Legacy 全额返还，能量与工程移除，开始新文明萌芽循环。迁移只执行一次，旧记录先校验再迁移；旧版 VI 已完成记录会随玩法重做重置。新版保存随机源、文明点位、完整战争、干预支出、轨道天赋逐级支付与核毁灭结算标记。余额统一推导为「累计获得 + 调试调整 − 地表天赋实付 − 轨道天赋实付 − 干预支出」。已有 v1–v15 迁移、有效备份与存储故障保护继续保留。


v10 → v11 为每个已购等级记录真实支付价格 `purchaseCosts`，免费赠予记录 0；旧天赋涨价不补扣，旧余额、战斗、奖励合同均保留。之后购买按新价格追加一笔，余额由累计收入减去实际支付账本恢复。

v9 → v10 不改变余额、历史支出、当前战场或结算凭据。当前轮保留旧遗产公式（`run.legacyRules = 9`），重建后启用指数公式；旧版已满级节点会出现新增等级。生产机默认未购买、进度与累计产出为 0，迁移不补发资源。v10 使用大数编码保存累计遗产、结算所得和机器累计产出；余额仍从总收入减去购买支出推导。

早期格式仍按各自历史规则检查：v1–v3 的免费功能及前置补偿继续保留；v4 补充挑战输入；v5 将在途伤害转换为发射快照；v6–v7 引入大数并保留已受基地伤害；v8 删除可推导属性副本。详见 [架构与迁移说明](docs/architecture.md)。

- 每 10 秒模拟时间自动保存；结算、继续冲突、购买升级、设置自动招募、重建及隐藏／关闭页面时立即保存。关闭期间**没有离线收益，也不推进战斗**。
- 战场底部「存档」从开局即可使用；解锁档案后也可从其中进入。该入口提供手动保存、JSON 导出、文件／文字导入和恢复上一份有效备份。导入先校验版本、字段类型、数值范围与状态一致性，再确认替换。
- 损坏或未知版本的原存档会被保护，自动保存停止覆盖；可恢复备份、导入有效存档或确认清空。此时仍可试玩、导出当前内存进度。
- 存储被禁用或空间不足时显示提示，游戏继续运行；请导出保存。另一标签页写入存档后，旧页面也会停止覆盖并提示刷新。
- 「清空全部进度」须明确确认，会删除永久进度及本地备份。导出的文件不受影响。存档按浏览器和站点地址隔离，切换端口或浏览器需导出再导入。
- 浏览器崩溃或强制结束可能丢失最近一次自动保存之后的操作；关闭事件只是额外保存机会，不替代定期保存。

### 快速调试

打开 `/?mode=debug`，或点击战场底部「快速调试」。顶部会显示「调试 · 独立存档」工具栏。

- 默认 **10 倍模拟速度**，可选 1／5／10／20 倍。训练、行军、战斗、冷却和自动招募一起加速，仍使用固定步长；空格或按钮暂停、打开天赋树／自动购买／存档／手册、隐藏页面均停止推进。
- 每个新文明额外提供 **10000 金币**，经验补足到可手动进化至未来；仍需点击进化或按 `E`，不会自动进化。读档不重复补发资源。「补充资源」可再次添加测试金币并补足经验。
- 「战役胜利」摧毁当前敌方基地；「终局结算」将敌人推进至未来后摧毁基地；「战败」摧毁我方基地。三者都走现有流程状态机，方便快速检查继续冲突、遗产、升级与重建。
- 调试存档和备份与正式增量模式完全分开，导出文件带 `debug` 标识，正式模式拒绝导入调试存档；清空调试进度不会清空正式进度。速度设置会随调试存档保留。

测试超级士兵：先在调试星图逐层解锁「超级士兵计划」，重建后连续按四次 `E` 进化至未来，再按 `4` 训练；初始只用匕首。购买狙击激光枪并重建后测试锁定射击。动画工坊搜索「超级士兵」可直接预览贴身短刺、锁定连线与狙击激光。

启航快速验证：`/?mode=debug` →「终局结算」→ 星图左下「调试 · 启航预算 +2²¹」→ 购买火种、五层各任意兵种节点、超级士兵计划 → 顶部存续协议（仍需在调试战斗中逐层结算到余烬第 5 层）。预算通过独立调试账目增加余额，不增加累计奖励或通关次数。也可在 `animations.html` 搜索 **轨道启航**，查看压缩为 8 秒的工坊预览。

最快验证：`/?mode=debug` 点「终局结算」→ 星图购买文明火种 → 重建 → 再次终局结算；第二轮后自动招募免费解锁且默认关闭。继续用终局按钮获取 Legacy，在每层买任意一个兵种天赋，直到超级士兵计划。工坊可直接查看所有特性和激光匕首，无需开局。调试存档独立，原有倍速档位保持不变；正式模式的 `R` 倍速使用正式存档的文明火种／时间加速解锁。

快速验证余烬远征：购买文明火种 → 遗产保存 1 → 余烬远征（共 7 Legacy），通关后选择「踏入纷争余烬」。敌方强化倍率仍在预览中列出；下一次终局应获 +4 Legacy，并可踏入「铁旗时代」（预览 +6）。结算页可直接重建返回初生之地，战败可重试同一片余烬。内部仍使用 0–10 的难度数值。

## 画面与动画

低饱和色块、无粗描边轮廓和少量明暗分面统一场景、部队与炮塔。战场、建造／招募卡和动态图鉴使用同一套模型。

恐龙采用双足承重，马采用四足错相步态。支撑脚按实际行进距离贴地，摆腿时抬脚。马的前腿分为肘、腕、球节与蹄，承重时较直、抬蹄时折收；后腿的膝关节向前、飞节向后，分别求解，避免反关节。攻击时恐龙探颈咬合、骑手同步送出石矛；重甲骑士握持带锥形枪身和护手的骑枪，保持枪身方向前送、沿原路收回，坐骑承重、缰绳和骑手随之联动；现代匕首兵以防护姿态蹬地短刺。武器保持固定长度，蓄力、接触与回收衔接实际命中时刻。

招募与炮塔预览采用实际模型的细线轮廓，保留武器、头盔、坐骑与机械结构，统一使用星图的灰绿色调。

动画工坊集中预览所有部队、炮塔、弹道与命中、大招、地面效果、基地和昼夜星空。搜索「文明毁灭」可逐帧检查首次通关演出，搜索「轨道启航」可预览后续离开废墟的镜头。支持分类／时代筛选、搜索、阵营与动作切换、¼ 倍／½ 倍慢放、暂停、逐帧、时间轴回放及点击放大；恐龙与马可开启步态辅助线。攻击预览使用真实战斗模拟，倒拖时间轴会恢复对应帧。

战斗表现按兵器区分：箭矢随重力弧线转向并嵌入目标，枪弹、坦克炮与能量弹直射；投石留下碎屑和尘土，榴弹与火箭产生短促爆焰和烟尘。沸油以液流下落，落地后形成带蒸汽的油池；箭雨留下箭簇，轰炸弹从飞机释放后继续向前下落。动画不改变伤害、射程和命中时序。

五代基地拥有不同的整体轮廓：原始时代是不规则巨岩、兽骨洞口和兽皮帐篷；中世纪是高尖顶与雉堞角楼；文艺复兴是赤陶屋顶和低矮星形棱堡；现代是宽体机库、卷帘门与扫描雷达；未来是开放式反应环、悬浮晶核和弯曲装甲翼。

炮位分别融入岩棚、城楼、斜面炮垒、屋顶指挥舱和装甲支臂；每次扩容增加连入主体的建筑结构，拆塔后保留炮座。受损细节与废墟也按时代区分。双方建筑朝向战场，手机上的模型与弹道同步缩放；动画工坊可直接对比五代基地。

昼夜每 120 秒对局时间循环一次，太阳、月亮、山峦与地面同步变化；星星以各自节奏闪烁。星空使用固定种子的二维分布，坐标按天空宽高归一化，窗口缩放和手机横竖屏切换时保持相对位置，不会因高度取余而排成直线。切换标签页、打开指挥手册或对局结束会暂停游戏，重开回到黎明。系统开启「减少动态效果」时，战场背景和模型动作保持静态；图鉴默认暂停，可手动播放。

### 本轮功能快速验收

打开 `/?mode=debug`，用「终局」完成两次文明，进入星图点亮文明火种；「调整遗产」输入 `128`，依次购买编队协议 → 技术托管 → 战术火控 → 连续征战。在自动购买中开启总开关、自动大招和自动继续，重建后点击调试「战役胜利」，应进入敌方下一时代且只领一次补给。下一次结算再买「赶尽杀绝」，重建后击败早期基地应直接获得文明遗产并回到星图。

购买余烬远征，逐关通关后在「选关」重返旧关或试下一关；失败后「重试」保持所选关卡，刷新保留最深进度。星图单击只看详情，双击购买一级。`npm test` 与 `/tests/` 共享新增自动化、选关、调试账目和 v14 迁移测试；浏览器另测开关、暂停、双击购买、刷新恢复及 320 / 390px 布局。
