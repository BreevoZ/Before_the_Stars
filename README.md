# Before the Stars

一款受《Age of War》启发的网页策略游戏。现已支持 **原始 → 中世纪 → 文艺复兴 → 现代 → 未来** 五个时代，每个时代有三种兵、三种炮塔、专属大招和基地外观。另有金币、经验、双方独立进化、训练队列、电脑对手及炮位扩容。

时代路线和兵器题材参考原版；文艺复兴的全军治疗也参考了原版机制，数值与战斗节奏为本项目重新设计。资料：[原版玩法与时代](https://flashgaming.fandom.com/wiki/Age_of_War)、[现代时代](https://aowg.fandom.com/wiki/Modern_Age)、[未来时代](https://aowg.fandom.com/wiki/Future_Age)。本版每时代保持三种兵，未加入原版未来时代的第四种超级士兵。

## 运行

原生 JavaScript、Canvas 2D 和 CSS，无需安装依赖或构建。在项目目录启动静态服务器：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

浏览器打开 <http://127.0.0.1:8000>。项目使用 ES modules，需要通过 HTTP 访问。

## 操作与胜负

- 左侧青色为我方，右侧橙色为电脑。摧毁敌方基地获胜，我方基地被摧毁则失败，同一模拟帧双方基地同时被摧毁为平局。对局可以在任何时代结束。
- 点击三张兵种卡片或按 `1` / `2` / `3` 加入训练队列；`空格` 训练第一种前排兵。
- 击杀赚取经验，达到下一时代门槛后点击进化或按 `E`；上方五段进度显示我方当前时代，敌方时代在敌基地血条下显示。
- 选中空炮位后点击炮塔卡片建造；`T` 在选中位置建造第一种炮塔。「扩容 +1」购买空炮位；选中已有炮塔可拆除并返还原价一半。
- 点击大招或按 `Q`：攻击大招进入瞄准，再点击战场释放，也可用左右方向键、`Enter` 释放、`Esc` 取消。**复苏之光直接施放，无需选点。**
- 点击「重开」或结算后的「再战一局」，重置双方时代、经验、基地、金币、队列、兵力、炮塔、扩容、大招及计时。切到其他标签页暂停。
- 支持手机触摸，训练与基地支援面板位于战场下方。

## 五个时代与独立进化

| 时代 | 进化所需累计经验 | 基地生命上限 | 每秒金币 | 基地外观 | 兵种 |
| --- | ---: | ---: | ---: | --- | --- |
| I · 原始时代 | 0 | 600 | 7 | 低矮石堡 | 近战兵、弓箭手、重装兵 |
| II · 中世纪 | 160 | 900 | 10 | 城垛与旗帜城堡 | 剑士、弩手、重甲骑士 |
| III · 文艺复兴时代 | 480 | 1500 | 16 | 砖石棱堡与拱门 | 决斗士、火枪手、炮兵 |
| IV · 现代时代 | 1100 | 2400 | 24 | 雷达混凝土碉堡 | 突击步兵、自动步枪兵、主战坦克 |
| V · 未来时代 | 2200 | 3800 | 36 | 发光能源要塞 | 光刃战士、等离子射手、战争机甲 |

- 双方分别从 0 经验开始，击杀敌军获得该兵种的经验和金币。炮塔及大招击杀也计入；多个攻击同时击杀只结算一次。等待、训练、退款、治疗和攻击基地不增加经验。
- 进化不花金币、不扣累计经验，每次升一个时代。玩家手动进化，电脑达到自己的门槛后独立进化；只有该方的基地、收入和可购兵种／炮塔发生变化。
- 进化保留已受伤害，当前生命增加新旧生命上限的差额。例如 `220 / 600` 变为 `520 / 900`。未来时代达到上限，不再进化。
- 招募和炮塔卡片随时代切换；旧兵保留原属性，已付款订单保留兵种、进度、原价和顺序，旧炮塔及扩容保留。不能再购买低于当前时代的兵或塔。
- 飞行中的弹药、已释放的大招及剩余冷却不会被进化重置。文艺复兴治疗在进化后继续生效至原定结束时间。任何新大招都必须等待现有冷却结束。

士兵自动前进，优先攻击射程内敌军，然后攻击基地。近战与重装单位在前排排队，远程射手使用后排，前排兵可越过己方射手。五个时代的部队可以共存。

护甲减少每次物理命中的伤害，最低 1 点；光刃战士的近战无视护甲。子弹、炮弹和能量弹都有飞行时间，单体弹药不会在目标死亡后转移伤害。炮兵、坦克、机甲分别有 **55 / 70 / 90** 的爆炸半径，范围内不伤友军，原目标死亡后仍会在最后追踪点爆炸。它们可直接攻击基地，但不会通过爆炸对基地重复结算。

## 金币与训练

- 初始双方各 180 金币，被动收入按各自时代结算，击杀另有奖励。进化不会赠送一次性金币。
- 购买立即扣费，按先后顺序逐个训练。队列最多 5 位，正在训练也占一位。
- 双方兵力上限各 16，场上部队和训练队列共同占用。
- 点击订单可取消，包括正在训练的订单，全额退还原始费用，其余订单保持顺序。
- 出口被同排友军堵住时，完成训练的士兵保留在队首，等出口腾空后出现。

| 时代 | 大招 | 生效方式 | 效果 | 冷却 |
| --- | --- | --- | --- | ---: |
| I | 陨星天降 | 0.8 秒后一次命中，半径 140 | 对敌军 110，无视护甲；对敌基地 40 | 40 秒 |

| III | 复苏之光 | 立即施放，持续 8 秒 | 全场存活友军每秒恢复 18 生命，期间新入场友军也受益 | 50 秒 |
| IV | 轰炸空袭 | 0.85 秒后首枚炸弹，每 0.4 秒一枚，共三枚，从左向右推进 | 落点为选点左右 140 及中央，每枚半径 95；对敌军 150，计算护甲；对敌基地 45 | 50 秒 |

## 电脑对手

电脑使用相同的时代收入、击杀奖励、经验门槛、单位属性、购买价格、训练时间和炮位规则，不免费出兵，也不因玩家进化获得经验。

开局 2.4 秒后，每隔 1.8 秒评估：经验达标则进化，使用当前时代的三种兵维持前排、补充远程并积攒重装单位费用；旧兵仍纳入阵容判断。18 秒后，基地受损或附近敌军较多时购买当前时代炮塔：密集敌军优先范围塔，装甲目标优先穿甲塔（没有则第一种塔），其余选最快射速。炮位已满且能负担扩容、新塔和一名前排兵时会扩容。电脑没有大招，通常只提前安排两名士兵。

```text
index.html          战场、五时代进程、经济、训练与防御界面
src/game.js         五时代配置、经济、训练、AI 和纯战斗模拟

tests/index.html    无依赖浏览器测试入口

```

数值集中在 `src/game.js` 的 `RULES`、`UNITS`、`AGES`、`TURRETS` 和 `ABILITIES`。逻辑与界面分离，使用固定步长更新。

启动服务器后打开 <http://127.0.0.1:8000/tests/> 查看结果。测试覆盖所有时代的购买与门槛、独立收入与进化、旧兵／订单／炮塔保留、15 种炮塔伤害、弹道与范围攻城、治疗及新大招、电脑行为、防透支、胜负冻结与重开，并包含使用正常资源推进至未来的完整对局。界面测试检查五时代卡片、快捷键、进度、瞄准和直接治疗；专用界面用例用测试模块设置初始资源，生产游戏没有调试接口。测试页保留各时代渲染预览，便于检查基地、部队、炮塔和效果。
