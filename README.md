# Before the Stars

一款受《Age of War》启发的网页策略游戏。

## 运行

使用原生 JavaScript、Canvas 2D 和 CSS，无需安装依赖或构建。
在项目目录启动静态服务器（Python 3）：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

在浏览器打开 <http://127.0.0.1:8000>。项目使用 ES modules，需要通过 HTTP 访问，不能直接双击 HTML 文件运行。

## 当前玩法

- 左侧为我方基地，右侧为敌方基地，双方基地各有 360 点生命。
- 点击「派出近战兵」或按空格招募一名近战兵，出兵冷却 1.5 秒，我方最多同时存在 16 人。
- 敌方在开局 2.4 秒后开始自动出兵，随后每 5 秒尝试出兵一次。
- 双方士兵属性相同：60 点生命、12 点攻击，每 0.8 秒攻击一次。
- 士兵自动推进，遇敌停下近战，前方无敌军时攻击对方基地；同队士兵排队前进。
- 摧毁敌方基地获胜，我方基地被摧毁则失败。双方基地同一帧归零时为平局。
- 点击「重开」或结算后的「再战一局」重置整个战场。切换到其他标签页时暂停战斗。

第一版只实现基础战斗循环，资源、升级和时代演进尚未加入。

## 文件结构

```text
index.html          页面与操作面板
src/game.js         战斗规则、状态和固定步长模拟
src/render.js       Canvas 场景、士兵和攻击动画
src/main.js         游戏循环、输入与界面同步
src/style.css       响应式页面样式
tests/index.html    无依赖的战斗逻辑测试入口
tests/game.test.js  战斗行为与完整对局回归测试
```

所有数值集中在 `src/game.js` 的 `RULES` 中。

## 验证

启动上述静态服务器后，打开 <http://127.0.0.1:8000/tests/>，页面会显示每项测试的结果。
测试覆盖出兵冷却、自动移动、交战与死亡、友军间距、基地伤害、胜负、结束后冻结，以及新局重置。
