# Before the Stars

一款受《Age of War》启发的网页策略游戏。目前支持部落、城堡两个时代，每个时代三种兵，以及金币、经验、独立进化、训练队列、电脑对手、基地炮塔和范围大招。

## 运行

使用原生 JavaScript、Canvas 2D 和 CSS，无需安装依赖或构建。在项目目录启动静态服务器（Python 3）：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

在浏览器打开 <http://127.0.0.1:8000>。项目使用 ES modules，需要通过 HTTP 访问，不能直接双击 HTML 文件运行。

## 操作与胜负

- 左侧青色为我方，右侧橙色为电脑；初始基地各有 600 点生命。摧毁敌方基地获胜，我方基地被摧毁则失败，同一模拟帧内同时被摧毁为平局。
- 点击兵种卡片或按 `1` / `2` / `3` 将当前时代的对应兵种加入训练队列；`空格` 训练第一种前排兵。
- 击杀获得经验，累计 160 经验后点击「进化至城堡时代」或按 `E` 进化。
- 点击「守卫炮塔」或按 `T` 建造炮塔。
- 点击「陨星天降」或按 `Q` 进入瞄准，再点击战场选择落点。键盘也可使用左右方向键瞄准、`Enter` 释放、`Esc` 取消。
- 点击「重开」或结算后的「再战一局」，重置双方时代、经验、基地、金币、队列、士兵、炮塔、大招与计时。切到其他标签页时暂停。
- 手机可触摸操作；训练与基地支援面板位于战场下方。

## 两个时代与独立进化

- **时代 I · 部落时代**：低矮石堡，可训练近战兵、弓箭手、重装兵。
- **时代 II · 城堡时代**：带城垛和旗帜的城堡，可训练剑士、弩手、重甲骑士。
- 双方分别从 0 经验开始，击杀敌军获得该兵种对应的经验。炮塔和陨石击杀同样计入，多个攻击同时击杀只结算一次。等待、训练、取消订单和攻击基地不增加经验。
- 累计 **160 经验**即可进化，不消耗金币，也不扣除累计经验。玩家手动进化，电脑在自己的经验达到门槛后独立进化；一方升级不会改变另一方的时代、经验或基地。
- 进化将该方基地的最大生命从 **600 增加到 900**，当前生命也增加 300，保留此前承受的伤害。例如 `220 / 600` 变为 `520 / 900`，不会直接回满。
- 进化后，三张招募卡片与 `1` / `2` / `3` 快捷键切换到新兵种。场上旧兵保持原属性，已付费的旧训练订单保持兵种、进度、价格与队列顺序；取消旧订单仍按原价退款。不能再新购上一时代的兵种。
- 已建炮塔、飞行中的弹药、大招与冷却不会被进化重置。目前最多两个时代，达到城堡时代后不能继续进化。

射程以战场逻辑坐标计，移速为每秒移动的逻辑距离。护甲减少每次物理命中的伤害，最低受到 1 点伤害。

## 金币与训练

- 双方初始各有 180 金币，每秒增加 7 金币，击杀敌军获得对应奖励。
- 购买时立即扣费，按先后顺序逐个训练。队列最多 5 位，当前训练也占一位。
- 双方兵力上限各为 16，已在战场的士兵和训练队列共同占用上限。
- 点击队列中的订单可以取消，包括正在训练的订单，全额退还该兵种费用。剩余订单保持原有顺序。
- 出口被同排友军堵住时，已完成训练的士兵会保留在队首，等待出口腾空后再出现。

## 基地支援

**守卫炮塔**：花费 120 金币在基地建造，每方最多一座。自动攻击距离基地 290 范围内最近的敌军，每 1.5 秒发射一枚 24 点物理伤害的炮弹，命中时结算。炮塔附属于基地，没有独立生命值，不会攻击对方基地。

**陨星天降**：玩家专属大招，不消耗金币，开局可用，释放后冷却 40 秒。选定落点 0.8 秒后落下，对水平半径 140 范围内的敌军造成 110 点无视护甲的伤害，对范围触及的敌方基地造成 40 点伤害，不伤害友军。瞄准时取消不会进入冷却；伤害按落地时的位置计算。

## 电脑对手

电脑与玩家使用相同的金币增长、击杀奖励、经验门槛、兵种属性、价格、训练时间、队列和炮塔规则，不会免费生成部队，也不会因玩家进化而自动获得经验。

开局 2.4 秒后，电脑每隔 1.8 秒评估一次：经验达标则进化，随后使用自己当前时代的兵种维持前排、补充远程、积攒金币训练重装单位；受到基地附近的压力时尝试建造炮塔。旧兵也会纳入兵种搭配判断。电脑没有大招，训练队列通常只提前安排两名士兵。

## 文件结构

```text
index.html          战场、经验进化、金币、兵种、队列和基地支援面板
src/game.js         两个时代、经验、经济、训练、AI 与战斗模拟
src/render.js       Canvas 场景、两种基地、六兵种、弹道和瞄准特效
src/main.js         固定步长游戏循环、键鼠触摸输入、界面同步
src/style.css       响应式页面样式
tests/index.html    无依赖的浏览器测试入口
tests/game.test.js  机制、完整对局与界面回归测试
```

数值集中在 `src/game.js` 的 `RULES`、`UNITS` 和 `AGES` 中；模拟逻辑与浏览器界面分离，使用固定步长更新。

## 验证

启动上述服务器后，打开 <http://127.0.0.1:8000/tests/>。测试页面展示每项结果，并用内嵌游戏检查按钮、快捷键、训练进度、取消退款、瞄准与重开。

逻辑测试覆盖金币收支与防透支、队列顺序和容量、不同兵种战斗、护甲、延迟弹道、击杀奖励、经验与升级门槛、双方独立进化、旧兵与订单保留、电脑行为、炮塔、大招范围和冷却、胜负后冻结及完整对局。界面测试还会通过正常战斗获取经验，实际触发进化，验证卡片、快捷键、血条和重开，并保留一张升级后战场的预览。
