# 地表文明：指数价格档

价格集中在 `progression-config.js`。基础结算奖励为 `2^(保存等级 + 传承等级)`；每翻倍一次便覆盖下一个 `2^n` 价格档的一项天赋。每个多级天赋的下一次价格也是当前的两倍。

| 进度 | 单项价格 |
| --- | --- |
| 火种 | 1 |
| 原始 → 中世纪 → 文艺复兴 → 现代 → 未来 | 2 → 4 → 8 → 16 → 32 |
| 超级士兵计划 → 狙击／精锐征召 | 64 → 128 |
| 遗产保存 1–8 级 | 2 → 256 |
| 文明传承 1–8 级 | 512 → 65,536 |
| 遗产生产机 | 8 |
| 平行档案 1–8 级 | 16 → 2,048 |
| 回响加速 1–6 级 | 32 → 1,024 |
| Great Filter Bypasser | 1,048,576（2²⁰） |

自动化与数值支线采用对应时代档位，详见 README。档案与兵种效果保持原值；调整的是标价及购买节奏。

## 终点预算

其它地表天赋全部买满共 **137,929** Legacy。Bypasser 是该总价的 **7.60 倍**，也等于满级普通终局奖励的 **16 次**。满级生产机为 **16,384／模拟分**，单靠机器需要 **64 模拟分钟**；实战会同时获得终局奖励与生产收益，远征也会显著加快积累。不额外要求全树满级，允许不同路线。

这些是保守原型值。价格档对应的是「下一笔完整基础收益可买一项」，不承诺零余额时每轮都能买完同层，也不承诺所有军队组合都有同样的通关时间。第一个保存升级仍需攒两份基础遗产；连续强化收益天赋通常需要先攒两个当前基础结算奖励。生产机、远征和旧有余额打破这个等待。

运行 `node sim/economy.js` 输出每次翻倍对应的天赋、全树预算及终点比例；`npm test` 验证各档关系和旧存档账本。战斗参数扫描继续使用 `npm run sim:batch`。

## 显示与旧账

绝对值达到 **1,000,000** 使用科学计数法。HUD 保留三位小数尾数，购买价保留六位以准确展示当前终点价格 `1.048576e+6`。展示舍入不改变实际支付与可购买判断。

v11 保存每个等级的实际支付价，v10 迁移按当时价格构造账本，旧赠予计 0。旧玩家无需补差价；升级后购买的下一等级按新标价支付。
